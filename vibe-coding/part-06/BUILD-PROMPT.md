Paste this into Lovable (in the box on your dashboard, with Build picked) or into Claude Code (in a new, empty folder). It builds the same tiny Test Bakery pre-order page in either tool, on made-up details only, so you can compare how each one feels. Lovable's free plan is enough to try it; Claude Code needs a paid Claude plan (Claude's Free plan didn't include it when checked on 2026-11-17, claude.com/pricing), and to install it, see Claude Code for Beginners on this channel. Written from Lovable's and Claude Code's docs, checked 2026-11-17.

Goal: build a one-page pre-order page for Test Bakery, a made-up neighbourhood bakery, with made-up details only.
Steps, in order:
1. Tell me in one sentence what you'll build, and wait for my OK.
2. Show three breads with prices: Sourdough loaf $6, Cinnamon roll $3, Rye bread $5. Next to each, a plus and a minus button and a number that starts at 0.
3. Show a running total at the bottom that updates as I change the numbers, and a Clear button that sets everything back to 0.
4. Use a warm, friendly style with large text, and make it work on a phone screen as well as a laptop.
5. No sign-in, no database, no payments, no forms that send data anywhere, and no outside services. Everything stays on this one page.
6. Check it yourself: the buttons change the numbers, the total is right, and Clear works. Tell me the result.
Safety: made-up details only, no real customer data, no secret keys.
Output: the page, how to open or preview it, and a three-line summary of what you built.
