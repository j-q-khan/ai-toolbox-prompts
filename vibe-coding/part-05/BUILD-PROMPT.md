Paste this into Claude Code in a new, empty folder. It builds a one-page Test Bakery website as plain files you keep on your own computer, on made-up details only, so you can compare it with the Framer site. Claude Code needs a paid Claude plan (Claude's Free plan didn't include it when checked on 2026-11-17, claude.com/pricing); to install it, see Claude Code for Beginners on this channel. Written from Claude Code's docs and Framer's help pages, checked 2026-11-17.

Goal: build a one-page website for Test Bakery, a made-up neighbourhood bakery, as plain HTML and CSS files in this folder, with made-up details only.
Steps, in order:
1. Tell me in one sentence what you'll build and which files you'll make, and wait for my OK.
2. Build one page with: a full-screen hero with the name Test Bakery and a short welcome line; a menu section with three breads (Sourdough loaf $6, Cinnamon roll $3, Rye bread $5); an opening hours section; and a contact section that shows test@example.com.
3. Use a warm, friendly style with large text, and make it work on a phone screen as well as a laptop.
4. No sign-in, no database, no forms that send data, no outside services, no fonts or images downloaded from the internet, and nothing outside this folder.
5. Check it yourself: the page opens in a browser with no errors, and every section shows. Tell me the result.
Safety: made-up details only, no real customer data, no payments, no secret keys. Change nothing outside this folder.
Output: the files, how to open the page in my browser, and a three-line summary of what you built.
