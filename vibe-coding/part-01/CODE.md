### 1. tip-splitter-prompt.txt
```
# Paste the first prompt into Lovable's box ("Ask Lovable to create…") with Build picked in the mode picker.
# Then send the change prompt on its own, after the first version is ready.
# Made-up numbers only. Written from Lovable's Quick start, checked 2026-11-17.
# To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files.
# On a Mac: open TextEdit, choose Format, then Make Plain Text, before you paste and save.

Build a tip splitter app: a box for the bill amount, buttons for 10%, 15% and 20% tip, and a box for how many people.
Show the tip, the total and what each person pays, updating as I type.
Clean, friendly design with large buttons. Works well on mobile.
No login or database yet.

# Change prompt, sent on its own:
Add a "Round up" button that rounds each person's share up to the nearest dollar. Keep everything else the same.
```

### 2. first-app-checklist.md
```
# Your first vibe coded app: checklist (facts checked 2026-11-17)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## Before you start
- [ ] A web browser and an email account. Same steps on Windows and Mac.
- [ ] Made-up details only. Lovable's terms say it may use what you build to train its AI models unless you tell it not to.
- [ ] For work: follow your employer's rules first.
- [ ] Lovable's free plan was 5 build credits a day, up to 30 a month, when checked on 2026-11-17 (lovable.dev/pricing).

## Build
- [ ] Sign up at lovable.dev with your email, or a Google, GitHub or Apple account.
- [ ] In the box "Ask Lovable to create…", check that Build is picked in the mode picker.
- [ ] Paste the first prompt from tip-splitter-prompt.txt. Keep its last line: No login or database yet.
- [ ] Wait for the first version. A few minutes is normal.
- [ ] Try it in the preview: $60, 15%, 4 people should show $17.25 each.

## Change it
- [ ] One change at a time, then check the preview after each.
- [ ] Send the change prompt. $17.25 should become $18 with Round up.
- [ ] Every change is saved as a version you can go back to.
- [ ] Click the device toggle above the preview until it shows Mobile view, and check every button fits.
- [ ] To change words, use Edit text inline in the preview toolbar: click the text, type, then Send. Each account gets 100 free inline text edits (each back 24 hours after use).

## Later (Part 2)
- [ ] Publish (top right) puts the app on a lovable.app link.

Sources: docs.lovable.dev/introduction/getting-started ; docs.lovable.dev/features/preview-toolbar ; docs.lovable.dev/prompting/prompting-one ; docs.lovable.dev/introduction/plans-and-credits ; lovable.dev/pricing ; lovable.dev/terms
```
