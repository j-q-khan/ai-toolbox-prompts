# Publish your Lovable website: checklist (facts checked 2026-11-17)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## Before you start
- [ ] A web browser and a Lovable account on the free plan. Same steps on Windows and Mac.
- [ ] Made-up details only. Lovable's terms say it may use what you build to train its AI models unless you tell it not to.
- [ ] For work: follow your employer's rules first.
- [ ] The free plan was 5 build credits a day, up to 30 a month, when checked on 2026-11-17 (lovable.dev/pricing).

## Build and change
- [ ] Paste the first prompt from bakery-website-prompt.txt with Build picked. Keep its last line: No login or database yet.
- [ ] One change at a time: what to build, where it goes, what must stay untouched.
- [ ] Select elements in the preview toolbar spends credits like a message. Edit text inline changes words with no prompt.
- [ ] More options under a reply shows Credits used.
- [ ] Only asking a question? Pick Chat in the mode picker: it answers without changing your site and uses a daily chat allowance first.
- [ ] Click the device toggle above the preview until it shows Mobile view, and check every section fits.
- [ ] Click every button and link before you publish.

## Publish
- [ ] Click Publish (top right, next to Share). Edit the suggested lovable.app link if you like.
- [ ] Look at the quick security scan line in the publish box.
- [ ] Click Publish again. When it finishes, Visit site opens your link.
- [ ] Your published site is a snapshot: after any change, click Publish, then Publish changes. A dot on Publish means changes are waiting. A published site doesn't use credits on its own, in Lovable's words.
- [ ] Optional: in the publish box, the visibility row can be set to Invite only (up to 10 people per app on Free and Pro).
- [ ] To take it down: Project settings, Publishing, Unpublish project.
- [ ] A custom domain (your own name, like testbakery.com) needs a paid plan (checked 2026-11-17).

## Keep your own copy
- [ ] Make a GitHub account at github.com if you don't have one.
- [ ] In the editor: Project settings, then Git, then GitHub, then Add account, then Install & Authorize in the GitHub window, then Connect. The status shows Connected.
- [ ] Lovable creates a new repository, private by default, and syncs both ways. Don't delete it: the sync stops.
- [ ] Download codebase (Project settings, Git) is on paid plans.
- [ ] Every change is saved as a version. History, top bar of the editor, lets you go back to one.
