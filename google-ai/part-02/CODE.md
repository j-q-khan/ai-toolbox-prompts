# Full code: Google AI Overviews: Can You Turn Them Off? How to Get Plain Results

The plain-results checklist and the devices file for this video, quoted from Google's own help pages with our notes marked (checked 2026-11-24). They were written from the docs, not run, and nothing was generated for this video.

### 1. plain-results-checklist.txt
```
# Plain Google results, per device (checked 2026-11-24). Not run: nothing was generated.
# Lines starting "Google says" are quoted from Google's help pages; lines starting "Our note" are this video's own notes, not Google's words.
# To keep a copy: paste this into Notepad and save it as plain-results-checklist.txt with the box called Save as type set to All files.
# On a Mac: open TextEdit, choose Format, then Make Plain Text, before you paste and save.
# Google says: "Features cannot be turned off." Our note: these steps give plain results; they don't switch AI Overviews off.

COMPUTER (any browser)
[ ] Search on google.com as usual.
[ ] Google says: "you can select the Web filter after you perform a search."
[ ] Google says: "Below the search box, select the type of results you want, like All, Images, or News." Our note: look there for Web.
[ ] Google says: "For more options, click More." Our note: if Web isn't showing, try More (Google doesn't say Web is there).
[ ] Our note: pick Web again on each new search.

ANDROID PHONE
[ ] Search in your browser or the Google app as usual.
[ ] Google says: "Below the search box, choose the type of results you want, like All, Images, or News."
[ ] Our note: Google doesn't say exactly where Web sits; look there and tap Web when you see it, again on each new search.

IPHONE
[ ] Search in your browser or the Google app as usual.
[ ] Google says: "Below the search box, select the type of results you want, like All, Images, or News."
[ ] Our note: Google doesn't say exactly where Web sits; look there and tap Web when you see it, again on each new search.

CHROME ON A COMPUTER (the AI Mode button)
[ ] Google says: "right-click on the address bar, then unselect Always show AI Mode."
[ ] Our note: this hides the AI Mode and Add tabs and more buttons. It does not turn off AI Overviews: use the Web filter for those.
[ ] Our note: Chrome's page describes no way to hide the button on the New Tab page.

A WRONG AI OVERVIEW (any device)
[ ] Our note: at the bottom of the overview, select the thumbs-down.
[ ] Google says: "To tell us more, click Report a problem and choose the category that best describes your issue."
[ ] Google says: "The feedback you submit includes your most recent search query and its search results." Our note: keep personal details out of the box.

# Sources: support.google.com/websearch/answer/14901683 (AI Overviews), support.google.com/websearch/answer/142143 (filters), support.google.com/chrome/answer/16704170 (AI Mode in Chrome), all checked 2026-11-24.
```
