# Part 2: Google AI Overviews: Can You Turn Them Off? How to Get Plain Results

Part 2 of 3 in the Google AI series: Google's own answer on switching AI Overviews off ("Features cannot be turned off"), the Web filter for plain results on a computer and a phone, hiding Chrome's AI Mode button, and reporting a wrong overview (facts checked 2026-11-24).

## What's here
- plain-results-checklist.txt: the steps from the video, per device. Lines starting "Google says" are quoted from Google's help pages; lines starting "Our note" are this video's own notes.
- devices.txt: the device list for the build prompt (computer, android, iphone, chrome).
- BUILD-PROMPT.md: a prompt for Claude Code that writes a small Python script making one printable checklist per device you list. It reads only the file you name, writes new files beside it, calls no Google service, installs no browser extension and changes no setting.
- CODE.md: the same prompt, as shown in the video.
- SOURCES.md: every Google help page the video's facts come from, with the date checked.

## How to use it
1. Search on google.com as usual, then pick Web from the list of result types below the search box (Google doesn't say exactly where it sits; look there, or under More).
2. To keep a copy of a file: paste it into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
3. Optional: save devices.txt into a new, empty folder, open Claude Code there and paste the prompt from BUILD-PROMPT.md.

Every screen in the video is drawn for it, and every results page is labelled "Example output". No browser extension is shown or recommended. Not affiliated with Google, Anthropic or Claude.
