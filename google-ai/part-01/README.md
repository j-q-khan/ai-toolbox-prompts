# Part 1: Google AI Mode: How to Use It in Search (and Delete Its History)

Part 1 of 3 in the Google AI series: the four ways into Google's AI Mode, asking with your voice, a photo or a file, finding and deleting AI Mode history (including the copies in My Activity), and what to check when AI Mode doesn't show up (facts checked 2026-11-24).

## What's here
- ai-mode-prompts.txt: prompts from the video that work well in AI Mode, each with a follow-up question, ready to paste.
- questions.txt: test questions for the build prompt (topic | what it's for | a limit).
- BUILD-PROMPT.md: a prompt for Claude Code that writes a small Python script turning short questions into fuller AI Mode prompts with two follow-ups. It reads only the file you name, writes one new file beside it, calls no Google service and asks before it writes anything.
- CODE.md: the same prompt, as shown in the video.
- SOURCES.md: every Google help page the video's facts come from, with the date checked.

## How to use it
1. Go to google.com/ai and paste one prompt from ai-mode-prompts.txt, then type its "Then ask" line as your follow-up.
2. To keep a copy of a file: paste it into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
3. Optional: save questions.txt into a new, empty folder, open Claude Code there and paste the prompt from BUILD-PROMPT.md.
