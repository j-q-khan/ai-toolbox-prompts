# Part 3: Google AI Essentials: Is the Course Worth It? Cost, Length and Certificate

Part 3 of 3 in the Google AI series: who Google AI Essentials on Coursera is worth it for, what it cost when checked, the trial and financial aid, how long it really takes (the page gives two figures), what the certificate is, and where Google Prompting Essentials fits (facts checked 2026-11-24).

## What's here
- worth-it-checklist.txt: the questions from the video, to decide whether the course is worth it for you. Lines starting "Coursera says" are quoted from Coursera's course page; lines starting "Our note" are this video's own notes.
- my-course-numbers.txt: the numbers for the build prompt (hours a week, and the monthly price you read off Coursera's page that day).
- BUILD-PROMPT.md: a prompt for Claude Code that writes a small Python script turning your numbers into a one-page decision sheet with your weeks and a rough cost. It reads only the file you name, writes one new file beside it, calls no website and signs in to nothing.
- CODE.md: the same prompt, as shown in the video.
- SOURCES.md: every Coursera and Google page the video's facts come from, with the date checked.

## How to use it
1. Open the course page (https://www.coursera.org/specializations/ai-essentials-google) and check today's price and wording: they change.
2. Go through worth-it-checklist.txt. To keep a copy of a file: paste it into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
3. Optional: put your numbers in my-course-numbers.txt, save it into a new, empty folder, open Claude Code there and paste the prompt from BUILD-PROMPT.md.
