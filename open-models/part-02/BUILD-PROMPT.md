1. Tell me in one sentence what you'll do, and that you'll ask me before running any command or writing any file.
2. Ask before running python --version on Windows, or python3 --version on a Mac (3.10 or later). If neither works, stop and tell me to get Python from python.org. Never install anything yourself.
3. Plan one file, fit_check.py, using only Python's standard library, and show me the plan first. It reads total memory (Windows: GlobalMemoryStatusEx through ctypes; Mac: sysctl -n hw.memsize), rounds it to whole GB, and reads graphics memory only through nvidia-smi if that command exists; otherwise it tells me to read Task Manager, Performance, GPU, Dedicated GPU memory. It also accepts a memory size in GB as an argument, so I can test it with a pretend number, and refuses anything that isn't a positive number. It holds this table, with its source and date in a comment: Qwen3.5-2B 2 GB, Qwen3.5-4B 4 GB, Qwen3.5-9B 7 GB, Qwen3.6-27B 16 GB, Qwen3.6-35B-A3B 20 GB (lmstudio.ai/models, "Minimum system memory", checked 2026-11-16). For each model it prints "too big" if it needs more than my memory, "tight" if less than a quarter of my memory would be left, otherwise "leaves room", and says that this is a rule of thumb, not LM Studio's. No network calls, nothing written to disk.

5. Ask before running python fit_check.py 8 and python fit_check.py 16 (python3 on a Mac), then python fit_check.py with no number, and explain the output in three plain lines. Remind me to re-check the figures on lmstudio.ai/models, since they can change.

7. Tell me the download can be several gigabytes, then ask before running lms get qwen/qwen3.5-4b -a (or lms get qwen/qwen3.5-9b -a if the script said the 9B leaves room), so I choose the download option myself; tell me to pick a 4-bit one (Q4_K_M, or 4bit on a Mac).
