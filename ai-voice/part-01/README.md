# AI Voice, Part 1: AI Voice Generator: Turn Text Into a Realistic Voiceover With ElevenLabs

Free files for the video. Facts checked 2026-11-26; plans and models change, so open each source before you rely on a line.

- voiceover-script-template.txt: a short example script written for text to speech (numbers as words, no symbols or emojis), plus a blank template for your own.
- settings-checklist.md: the Text to Speech steps, the docs' starting settings, the free plan's commercial-use and attribution rules, dated prices, YouTube's disclosure page, and four free options with their licences, each with its source.
- BUILD-PROMPT.md: paste it into Claude Code in an empty folder to build a local page that splits a script into chunks under a character limit and flags hard-to-say words. It uses only the text you paste in, downloads nothing and runs no third-party code.
- CODE.md: both files above in one place, exactly as shown in the video.
- SOURCES.md: every page the facts come from, with the date it was checked.

Nothing in this folder was generated with any voice tool, and no audio was made for the video. This is not legal advice. Not affiliated with ElevenLabs, Google, YouTube, CapCut, the Open Home Foundation or the Kokoro project.
