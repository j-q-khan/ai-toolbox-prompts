# AI Voice, Part 2: AI Voice Cloning: Clone Your Own Voice With ElevenLabs, the Safe Way

Free files for the video. Facts checked 2026-11-26; plans and docs change, so open each source before you rely on a line.

- recording-checklist.md: whose voice you may clone, the room, the microphone, the performance, the length and file type for an Instant or Professional Voice Clone, the plans with dated prices, the steps, and YouTube's disclosure line, each with its source.
- consent-note-template.txt: a plain consent note for when another adult agrees to an Instant Voice Clone of their voice (18 or over only). Not legal advice.
- BUILD-PROMPT.md: paste it into Claude Code in an empty folder to build a local page with the recording checklist and a consent-note filler. It uses only what you type in, never asks for your microphone, downloads nothing and runs no third-party code.
- CODE.md: both files above in one place, exactly as shown in the video.
- SOURCES.md: every page the facts come from, with the date it was checked.

Nothing in this folder was made with any voice tool, and no audio was recorded or generated for the video. This is not legal advice. Not affiliated with ElevenLabs or YouTube.
