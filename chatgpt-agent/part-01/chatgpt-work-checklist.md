# ChatGPT Work explained: checklist (facts checked 2026-11-19, from OpenAI's own pages)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## What you need
- [ ] A ChatGPT account. Pricing page, Work row: Free and Go "Limited (desktop app)"; Plus and Pro "Desktop, web, and mobile" (checked 2026-11-19).
- [ ] Prices in OpenAI's pricing docs when checked on 2026-11-19: Free $0, Go $8, Plus $20, Pro from $100 a month (tiers $100, $200, $500); Business $20 per user a month billed annually, $25 billed monthly; Enterprise: contact sales. Check https://chatgpt.com/pricing and https://learn.chatgpt.com/docs/pricing before you pay.
- [ ] For Free and Go, or for Local tasks: the ChatGPT desktop app, offered for macOS (Apple Silicon), Windows and Linux: https://learn.chatgpt.com/docs/app
- [ ] Work or school workspace: OpenAI says Work is available "for eligible plans and workspaces", so ask your admin.

## Chat or Work
- [ ] In the desktop app, use the toggle above the message box to pick Chat or Work.
- [ ] Chat: an answer, an explanation, a brainstorm, a short draft, quick questions and short rewrites.
- [ ] Work: a task with a clear outcome you can check, like a brief, a deck, a spreadsheet or a recurring update.

## Local or Cloud (desktop app)
- [ ] Local: the task runs on your computer and can use its files and apps.
- [ ] Cloud: the task runs without your computer, e.g. a scheduled website check.
- [ ] Pick before you send: a running task can't switch from Local to Cloud.

## Your first request
- [ ] Switch to Work, paste first-work-request.txt, send it.
- [ ] Answer its two questions.
- [ ] Check: you get a one-page brief with Decisions, Open questions, Owners and dates, and a Not in the notes list.
- [ ] Check every line against the notes before you use it.

## While it works
- [ ] You can follow progress, answer questions, change direction and approve important actions.
- [ ] Before consequential actions, such as a booking or a payment, Work asks for confirmation. Say no if you're not sure.
- [ ] If a task pauses for a safety review, follow the notice before continuing.
- [ ] Never type a password into the chat. Safety settings are Part 4 of this series.

## Limits to expect
- [ ] Work and Codex share pricing, credits and usage limits. OpenAI's pricing docs estimate Plus usage in local messages per five-hour period; Pro plans currently have no five-hour limit; weekly limits may also apply. Longer or more complex tasks may use more credits.
- [ ] Some sites block automated browsers or require a CAPTCHA. If it's blocked, you can take over its computer.
- [ ] The cloud browser is on paid plans other than Free and Go.
- [ ] Computer Use (ChatGPT using desktop apps) is in supported regions only, on macOS and Windows: https://learn.chatgpt.com/docs/computer-use

## Shortcut
- [ ] To aim a task at one plugin, type @ and the plugin name in your message, e.g. @Google Drive. Plugins are under Customize, then Plugins.
