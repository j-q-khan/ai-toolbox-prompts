# ChatGPT Work: your first task, checklist (facts checked 2026-11-19, from OpenAI's own pages)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## What you need
- [ ] A ChatGPT account. Pricing page, ChatGPT Work: Free and Go "Limited (desktop app)"; Plus and Pro "Desktop, web, and mobile" (checked 2026-11-19): https://chatgpt.com/pricing
- [ ] On Free or Go: the ChatGPT desktop app, offered for macOS (Apple Silicon), Windows and Linux: https://learn.chatgpt.com/docs/app
- [ ] The prompt first-work-task.txt, from the link in the description.

## Switch Work on
- [ ] Desktop app: choose ChatGPT (not Codex, OpenAI's coding tool), then use the toggle above the message box to pick Work. OpenAI's quickstart gives one set of steps for macOS, Windows and Linux.
- [ ] Website (Plus and Pro): turn on Work in the switcher. On the web, Work runs in a managed cloud environment.
- [ ] Desktop app, if offered Local or Cloud: Local uses files, apps or the browser on your computer; Cloud runs in an isolated hosted environment. For this task, pick Cloud. No choice shown? Carry on.

## Give it the task
- [ ] Copy everything in first-work-task.txt below the # lines, paste it into the message box with Work switched on, and send it.
- [ ] Answer its two questions: who the summary is for, and which kind of file you want.

## While it works
- [ ] It shows its progress and pauses when it needs information or approval.
- [ ] The chat sidebar can show its plan, its sources and the files it makes.
- [ ] Before consequential actions, such as a booking or a payment, Work always asks for confirmation. This task shouldn't need one: if it asks to visit a website or send anything, say no.
- [ ] If a task is blocked on a website, you can take over its computer and use it yourself. Logins, permissions and take over are Part 4 of this series.

## Where the file lands
- [ ] Desktop app: generated documents, presentations, spreadsheets and PDF files open in a preview alongside the chat; with automatic previews on, the app can open the file when the task finishes.
- [ ] Website: review the file in the chat and download it when you need it.
- [ ] The prompt asks it to tell you the file's name and where it saved it.

## Check it worked
- [ ] Open the file and go through every heading.
- [ ] Sums from the dummy table: Mugs 300, Caps 700, total 1,000; January 250, February 250, March 500 (the best month).
- [ ] Ask it: "What assumptions did you make?"
- [ ] It lists what the table doesn't say, such as costs or profit.
- [ ] OpenAI: "A polished response can still be incomplete or wrong, so review the details that matter before you use or share it."

## Fix one part
- [ ] In the desktop app's preview, point at one part of the file (an annotation) and ask for that one change, without starting over.
- [ ] Sent it with the wrong choice (Local or Cloud)? Cancel the run and press the up arrow key in the message box to get your prompt back (OpenAI's troubleshooting page).

## Afterwards
- [ ] This task used no websites, sign-ins or plugins, so there's nothing to clear.
- [ ] If a later task used Work's cloud browser: Settings, then Cloud browser, then Browser data, then Clear all signs you out of websites in Work's browser.
- [ ] Never type a password or a card number into the chat. Safety settings are Part 4 of this series.
