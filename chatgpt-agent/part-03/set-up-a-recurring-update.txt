Goal: plan a weekly status note for [project], made from the made-up to-do list at the end of this message.
Steps, in order:
1. Before you start, ask me which day and time I'd like the note each week, and wait for my answer.
2. Use only the list in this message. Don't visit any website, don't use any plugin, don't open any of my files, and don't send the note to anyone.
3. Write this week's status note in this chat, with three headings: Done, Still open, Blocked. Keep it under 150 words.
4. Then describe the scheduled task you would set up to refresh this note each week at the time I gave: what it would do each time and what it would use. Don't create the scheduled task.
5. Stop.
Rules: ask me before you visit a website, sign in, buy, send or delete anything. Never ask me for a password or a payment detail. If anything is unclear, ask me first.
Reminder for me: check the note against the list before I use it.
