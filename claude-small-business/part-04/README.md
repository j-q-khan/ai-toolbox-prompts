# Claude for Small Business, Part 4: Claude for Outlook: Install the Add-in, Draft Replies and Find Meeting Times

Free files for the video. Facts checked 2026-11-26; plans, prices and screens change often, so open each source before you rely on a line.

- `claude-for-outlook-setup-checklist.md`: a dated setup checklist for Claude for Outlook: the plan, which Outlook it runs in, installing it from Microsoft AppSource, where the Claude button is in each Outlook, mailbox access and the four permissions it asks for (in Microsoft's words), reviewing every draft before it's sent, and how the Microsoft 365 connector differs.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable setup checklist page from the dated facts. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, the same as the Full code in the video's script.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Every example in the video uses made-up mail (Harbor Street Florist, Test Café, Example Events, test@example.com). Nothing was signed up for, signed in to, installed or run for the video. Not affiliated with Anthropic, Google or Microsoft.
