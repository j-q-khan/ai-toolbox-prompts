# Claude for Small Business, Part 2: Claude in Chrome: Install the Extension and Let Claude Use Websites Safely

Free files for the video. Facts checked 2026-11-26; plans, settings and menu names change often, so open each source before you rely on a line.

- `claude-in-chrome-safety-checklist.md`: a dated safety checklist for Claude in Chrome: who can get it, the second Chrome profile, the install steps, what the extension can see and do in Anthropic's words, the three permission modes, what it always asks and never does, prompt injection, how to take access back, and what to try if it won't work.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable one-page safety checklist from the dated facts. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Every example in the video uses made-up data (Harbor Street Florist, Test Flower Supply, test@example.com). Nothing was signed up for, signed in to, installed or run for the video. Not affiliated with Anthropic, Google or Microsoft.
