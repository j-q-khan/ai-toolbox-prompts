# Claude for Small Business, Part 3: Claude for Research: Find Sources and Papers You Can Check

Free files for the video. Facts checked 2026-11-26; settings, plans and menu names change often, so open each source before you rely on a line.

- `source-check-checklist.md`: a dated source-check checklist for research with Claude: a research prompt to copy, turning on web search, what Research can reach, the two checks for every citation (does the page open, does it say what's claimed), a table to log each one, and what to check before you use the answer.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable source-check sheet from the dated facts. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Every example in the video uses made-up data (Harbor Street Florist, and source links ending in .example, which no real site uses). Nothing was signed up for, signed in to, searched or run for the video. Not affiliated with Anthropic, Google or Microsoft.

The prompts and files here are free to use (MIT licence).
