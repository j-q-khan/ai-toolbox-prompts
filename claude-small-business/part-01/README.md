# Claude for Small Business, Part 1: Claude for Business: Set Up the Small Business Plugin and Run Your First Workflow

Free files for the video. Facts checked 2026-11-26; plans, prices and connector lists change often, so open each source before you rely on a line.

- `small-business-setup-checklist.md`: a dated checklist for setting up Claude's Small Business plugin: the plan and its price when checked, the install steps, what each connector can see in Anthropic's words, the ask-first settings, and how to check your first Monday brief against your books.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable one-page setup checklist from the dated facts. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Every example in the video uses made-up data (Harbor Street Florist, Test Café, test@example.com). Nothing was signed up for, signed in to or run for the video. Not affiliated with Anthropic, Google or Microsoft.

The prompts and files here are free to use (MIT licence).
