# Full code: Gemini for Studying: How to Use Guided Learning, Step by Step

The study prompts, the button path and the quiz-yourself checklist from this video, written from Google's Gemini Apps help pages (checked 2026-11-27). They were written from the docs, not tried on a real account. The topics in them are examples; swap in your own.

### 1. guided-learning-study-prompts.txt
```
# Gemini Guided Learning: study prompts (facts checked 2026-11-27)
# To keep a copy: paste into Notepad and save with the box called Save as type set to All files,
# as guided-learning-study-prompts.txt. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
# Fill in the [square brackets] with your own topic, level and goal.

# Where to paste (from Gemini Apps Help, answer 16448384):
# gemini.google.com (signed in)
# Add Files (in the text box)
# More tools (bottom of the menu)
# Guided Learning
# Type your topic → Submit
# On a phone: Add Files → Guided Learning (still arriving gradually; use the website if it's missing)

1. Help me study [photosynthesis] for [a test on Friday]. I'm [a beginner], and all I know is [that plants need sunlight]. Make me a study plan first, then teach me one piece at a time and ask me a question after each piece.
2. Draw a simple diagram of [a leaf] to explain this.
3. Give me five multiple choice questions with hints.
4. Create a quiz about [photosynthesis]
5. Create flashcards about [adding fractions]
6. I don't know. Can you explain that part another way?

# Quizzes and flashcards open in Canvas, a panel on the right (Gemini Apps Help, answer 16275879).
# @OpenStax uses OpenStax textbooks: English only, United States only, not under 18, not on work or school accounts.
```

### 2. gemini-study-checklist.md
```
# Gemini Guided Learning: quiz-yourself checklist (facts checked 2026-11-27)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files, as gemini-study-checklist.md. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## Before you start
- [ ] Signed in to Gemini at gemini.google.com ("To use this feature, you must be signed in to Gemini Apps.")
- [ ] Opened Add Files → More tools → Guided Learning (phone: Add Files → Guided Learning)
- [ ] My prompt says the topic, my level, what I already know, and my goal
- [ ] Asked for a study plan first

## During the session
- [ ] Answered each question myself before looking anything up
- [ ] Typed "I don't know" when stuck, and asked for that part another way
- [ ] Asked for a diagram where the topic is hard to imagine
- [ ] Videos not showing? Checked History (the History button at gemini.google.com; On or off shows near the top). Google: "If you're 18 or over, History is on by default." Work or school account: the admin sets it.

## Testing myself
- [ ] "Create a quiz about [topic]" (opens in Canvas, on the right)
- [ ] "Create flashcards about [topic]"
- [ ] "Give me five multiple choice questions with hints."
- [ ] Went through the cards I missed again
- [ ] Work or school account: quizzes and flashcards can't be shared

## Good to know
- [ ] Guided Learning: Google's help page gives no age, country or plan limit for it. Gemini itself: 13 or over (or the age your country sets) on a personal or school account.
- [ ] @OpenStax textbooks: English only, United States only, not under 18, not on work or school accounts.
- [ ] Need a researched report instead? That's Deep Research (Add Files → Deep Research; 18 or over; usually about 5-10 minutes).
- [ ] Studying from my own notes? That's NotebookLM (also listed as Gemini Notebook).

Sources: support.google.com/gemini/answer/16448384 ; support.google.com/gemini/answer/16275879 ; support.google.com/gemini/answer/13278892 ; support.google.com/gemini/answer/15719111 ; support.google.com/gemini/answer/13278668 ; blog.google (Guided Learning, Sep 23, 2025)
```
