# Gemini for Home and Work, Part 2: Gemini for Workspace: How to Use Gemini in Gmail and Google Docs

Free files for the video. Facts checked 2026-11-26. Which plan gets which feature, and the prices, change often, so open each source before you rely on a line.

- `gmail-reply-prompts.txt`: ready prompts for Help me write and Ask Gemini in Gmail, with where to paste each one. Fill in the square brackets with your own details.
- `docs-rewrite-prompts.txt`: ready prompts for the Gemini bottom bar, Refine and the side panel in Google Docs, with the button paths.
- `gemini-gmail-docs-checklist.md`: a dated checklist of which Workspace plan and which Google AI plan gets Gemini in Gmail and Docs, the side panel, privacy in Google's words, and the admin switch.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder. It builds a one-page prompt picker that shows the right Gmail or Docs prompt and which button to paste it into. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the files above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Everything in the video was written from Google's help pages. Nothing was tried on a real account, and nothing was signed up for, signed in to or run. Outputs shown are labelled "Example output", and every name, shop and email address is made up. Not affiliated with Google.
