# Sources: Claude Code in VS Code: Beginner Tutorial for the Extension

Part 3 of the Claude Code for Beginners series.

- Claude Code in VS Code (2026-11-13): https://code.claude.com/docs/en/vs-code "VS Code 1.94.0 or later"; "any paid Claude subscription (Pro, Max, Ultra, Team, or Enterprise) or a Claude Console account works"; "The extension bundles its own copy of the CLI (command-line interface) for the chat panel. To run `claude` in VS Code's integrated terminal, you also need the standalone CLI install."; "press `Cmd+Shift+X` (Mac) or `Ctrl+Shift+X` (Windows/Linux) to open the Extensions view, search for "Claude Code", and click **Install**."; "Status Bar: click **✻ Claude Code** in the bottom-right corner of the window. This works even when no file is open."; the Spark icon "only appears when you have a file open"; "The first time you open the panel, a sign-in screen appears. Click **Sign in** and complete authorization in your browser."; "After you sign in, a **Learn Claude Code** checklist appears… dismiss it with the X"; "In Manual mode, when Claude wants to edit a file, it shows a side-by-side comparison of the original and proposed changes, then asks for permission. You can accept, reject, or tell Claude what to do instead."; "click the mode indicator at the bottom of the prompt box to switch permission modes"; "Manual: Claude asks permission before file edits and most shell commands"; "VS Code reads `initialPermissionMode` from your user settings and ignores workspace values."; extension settings "Open with `Cmd+,` (Mac) or `Ctrl+,` (Windows/Linux), then go to **Extensions > Claude Code**"; rewind: "Hover over any message to reveal the rewind button", options "Fork conversation from here", "Rewind code to here" ("revert file changes back to this point in the conversation while keeping the full conversation history"), "Fork conversation and rewind code"; "Check workspace trust: The extension doesn't work in Restricted Mode"; "Installing the extension does not put `claude` on your shell PATH."
- Permission modes (2026-11-13): https://code.claude.com/docs/en/permission-modes auto is the built-in starting mode "for interactive terminal and VS Code sessions" from v2.1.283; "Auto mode reduces permission prompts but does not guarantee safety."; VS Code tab: labels Manual = `default`, Edit automatically, Plan, Auto, Bypass permissions; "The extension starts each new conversation in the first of these that applies: 1. `claudeCode.initialPermissionMode` 2. The mode you last picked from the mode indicator, if it was Manual, Edit automatically, or Auto… 3. `permissions.defaultMode` from managed settings or `~/.claude/settings.json` 4. The built-in default"; "The extension never reads a project's `.claude/settings.json` or `.claude/settings.local.json` for the starting permission mode."; "The setting doesn't accept `auto`"; "On Pro, Max, Ultra, and Team plans… Claude Code asks once whether to change the setting to auto mode. The question appears in the terminal or in the VS Code extension, and if you decline, your setting stays as it is."
- Extension manifest (2026-11-13): https://open-vsx.org/api/Anthropic/claude-code (v2.1.323, published 2026-11-12) display name "Claude Code for VS Code", publisher Anthropic, engine `^1.94.0`; `claudeCode.initialPermissionMode` enum `default`, `manual`, `acceptEdits`, `plan`, `bypassPermissions`, "'manual' is an alias for 'default', the mode labeled Manual in the UI; set either to always start in Manual."; command "Claude Code: New Conversation".
