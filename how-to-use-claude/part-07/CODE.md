```
# Choosing a Claude plan: Free, Pro or Max (from Anthropic's pages, checked 2026-11-14)

## What each plan adds (each includes everything in the one before)
- [ ] Free ($0): limited usage; chat on web, desktop and phone; web search; artifacts; memory; connected apps; up to 5 Projects; Sonnet and Haiku.
- [ ] Pro (was $20 a month, or $200 a year up front): more usage than Free (at least 5x per 5-hour session, the pricing page's FAQ says); Research; Claude Code; Opus; Projects without the cap of 5; hand off and schedule tasks; usage credits; Fable runs on usage credits.
- [ ] Max (was $100 a month, monthly only): 5x Pro usage every 5 hours and every week; Fable included, up to half your weekly limit; $100 a month in Claude Platform credits for building apps (not for chat usage; claimed on claude.ai in a web browser after seven days on the plan; unused credits expire each billing cycle).
- [ ] Ultra (formerly Max 20x, was $200 a month): 10x Pro usage every week; no 5-hour limit for verified accounts.
- [ ] Anthropic publishes no exact message counts for any plan. Ignore any number that isn't on its pages.
- [ ] Privacy is the same on every individual plan: model training is listed as Opt-out, and the Model Improvement setting is in Privacy Settings.

## Questions about your own week
- [ ] How often do you see the limit message? Never: stay on Free. Often on Free: Pro. Most days on Pro: Max.
- [ ] Do you need Research, Claude Code or Opus? They start on Pro.
- [ ] Would you use Fable a lot? It's included on Max; on Pro it runs on usage credits.
- [ ] Do you build your own apps on the Claude Platform? Only then do Max's monthly platform credits matter.

## Before you pay
- [ ] Check claude.com/pricing on the day: prices exclude tax, vary by region, and app store prices can differ.
- [ ] Only run out now and then on Pro? Try usage credits first (Pro, Max and Ultra; not Free): Settings, then Usage, then the Usage credits toggle, "Adjust limit" for a monthly spend limit, then "Buy usage credits". Billed on top of your plan; purchases are non-refundable.
- [ ] When you upgrade (claude.ai/upgrade), your new plan's limits apply right away.

Help pages: support.claude.com, "What is the Pro plan?", "What is the Max plan?" and "What is the Ultra plan?".
```
