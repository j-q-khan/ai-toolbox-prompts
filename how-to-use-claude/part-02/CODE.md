```
# Claude desktop app: setup checklist (from Anthropic's help pages, checked 2026-11-14)

## Before you start
- [ ] A Claude account (the free plan is fine).
- [ ] Windows 10 or later, or macOS 13 (Ventura) or later. Linux (beta): Ubuntu 22.04 LTS+ or Debian 12+, x64 or arm64.

## Windows
- [ ] Go to claude.com/download and click Download next to Windows (or Windows arm 64 on an Arm laptop).
- [ ] Open the file you downloaded.
- [ ] When Windows asks to allow the app to make changes, click Yes. Without administrator rights Claude still installs, but Cowork on desktop won't be available.
- [ ] Launch Claude from the Start menu and sign in (Continue with Google, or Continue with email).

## Mac
- [ ] Go to claude.com/download and click Download next to macOS (one download for Intel and Apple chips).
- [ ] Open the file you downloaded and drag Claude into your Applications folder.
- [ ] Launch Claude from your Applications folder and sign in.

## Linux (beta), Ubuntu or Debian
- [ ] Follow "Installation steps for Linux" on Anthropic's install page (it uses Anthropic's apt repository):
      https://support.claude.com/en/articles/10065433-install-claude-desktop
- [ ] Copy the commands from that page only, and check the signing key fingerprint it gives.
- [ ] Updates come with your system's package updates (the app doesn't update itself on Linux).

## What to try first
- [ ] Mac: double-tap Option for quick entry (Settings, then Desktop app, then Quick access shortcut). Voice dictation on Caps Lock is off by default and needs macOS 14+.
- [ ] Desktop extensions: Settings, then Desktop app, then Manage, next to Extensions. Only add what you trust and need.
- [ ] Paid plans: Cowork works in folders you connect; Claude Code is in the Code tab.

## Good to know
- [ ] The app and the browser share one usage limit. Help pages: support.claude.com
```
