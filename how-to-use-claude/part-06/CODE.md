```
# Making your Claude usage last (from Anthropic's help pages, checked 2026-11-14)

## Know your two limits
- [ ] Session limit: a five-hour window that starts with your first message and refills in full five hours later. Free has one too.
- [ ] Weekly limit (paid plans): resets at a fixed day and time assigned to your account, not seven days after you start.
- [ ] The Claude website, the desktop app and Claude Code share the same limit.
- [ ] Anthropic publishes no exact message counts, and it may adjust limits to manage capacity.

## Check where you stand (paid plans)
- [ ] Settings > Usage > Plan usage limits: Current session (used so far, time left) and Weekly limits (when they reset).
- [ ] On Free, Claude tells you when you've reached your limit.

## Make it last
- [ ] Chat getting long? Start a new one, and paste in a short handover note instead of the whole history.
- [ ] Files you use again and again go in a Project: they're cached and count less when reused.
- [ ] Coming back to a Project after a long break? Put all your questions in that first message, because cached files are counted in full again.
- [ ] Group related questions into one message instead of several.
- [ ] Routine job? Model name next to the send button > Effort > Low or Medium.
- [ ] Turn off connected apps the chat doesn't need, and ask Claude not to search the web when you don't need current information.
- [ ] Use Research only when the question needs a full report: it can use your limits faster.

## When you hit the limit
- [ ] Wait: the time is in Settings > Usage.
- [ ] Upgrade: the new plan's limits apply right away (compare plans at claude.com/pricing).
- [ ] Usage credits (Pro, Max, Ultra): Settings > Usage > Usage credits toggle, then "Adjust limit" to set a monthly spend limit, then "Buy usage credits" (they only kick in once you have credits). Billed on top of your plan; purchases are non-refundable.
- [ ] Limit reset: only if Anthropic has given you one. "Reset for free" in Settings > Usage > Limit resets (web, desktop or mobile app; not in Claude Code's terminal), or on the limit message. It can't be undone.

Help pages: support.claude.com, "How do usage and length limits work?" and "Usage limit best practices".
```
