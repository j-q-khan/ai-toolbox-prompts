# Full code: Claude Design for Websites: Mock Up a Landing Page, Then Hand It to Claude Code

The bakery brief and a handoff checklist, written from Anthropic's own pages (checked 2026-11-15). Plain text only; nothing was signed into, generated or run.

### 1. pebble-lane-landing-brief.txt
```
# pebble-lane-landing-brief.txt: a made-up brief for your first Claude Design landing page
# Pebble Lane Bakery is not a real business. Use made-up briefs like this, never client files.
# Paste it after Output, then Design in the message box (Settings, then Capabilities, then Create and edit files must be on).
Page: a landing page that signs people up for the Pebble Lane Bakery Saturday bread class.
Who it's for: local beginners who have never baked bread.
Layout: a big heading, one short line under it, the four dates, the price, and one button that says Book a place.
On the page: four Saturday mornings, 10:00 to 13:00, 25 dollars a place, flour and aprons included.
Phones: it must work on a phone as well as a laptop.
Then: make the Book a place button open a booking screen with the four dates and a name and email form (for show only; use hello@pebblelane.example).
Also say: mark every screen as a draft, and use only these facts.
```

### 2. handoff-checklist.txt
```
# handoff-checklist.txt: before and after you hand a Claude Design page to Claude Code
# From Anthropic's pages "Get started with Claude Design", "Set up Claude Code",
# "Claude Code on the web" and "Artifacts" (all checked 2026-11-15).
[ ] Click through the prototype: does Book a place open the booking screen? If not, say so in the chat
[ ] No Claude Code? Export, then Export as standalone HTML gives you the page as one file
[ ] Claude Code needs Pro, Max, Ultra, Team or Enterprise (not the Free plan), installed and signed in
[ ] Export, then Handoff to Claude Code, then pick one:
[ ]   Send to local coding agent: Claude Code on your own computer
[ ]   Send to Claude Code Web: Claude Code in the cloud (Pro, Max, Ultra, Team; Enterprise with the right seats)
[ ] Open the page Claude Code builds in your web browser and put it beside your mock-up
[ ] Something missing? Tell Claude Code in plain words what's different
# The other way round: in Claude Code 2.1.265 or later, /design with a brief drafts a Claude Design canvas (templates are in beta).
# Netlify, Vercel and Wix are on the Export list under "Send to the tools you already use"; each needs its own account.
```
