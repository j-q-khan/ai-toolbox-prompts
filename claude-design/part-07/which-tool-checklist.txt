# which-tool-checklist.txt: Claude Design, Figma, or both? Checked 2026-11-15.
# Built only from Anthropic's and Figma's own pages. Names and plans can change: check the pages on your day.
# Sources: support.claude.com articles 14604416 (get started) and 14604397 (design system);
# claude.com/connectors/figma; help.figma.com articles 32132100833559, 42495251338775, 39252411778583
[ ] New, need a one-pager, deck or page mock-up to show today: start in Claude Design (every Claude plan, Free included).
[ ] Team already designs in Figma: keep the files in Figma; bring frames into Claude with Figma's connector.
[ ] Building an app: Figma for the team's files, Claude for turning frames into code; or Claude Design, then Handoff to Claude Code.
[ ] Claude Design export list: zip, PDF, PPTX, Google Slides, standalone HTML, Handoff to Claude Code.
[ ] Also sends to: Adobe Experience Manager, Adobe for Creativity, Adobe Journey Optimizer, Base44, Canva, Gamma, HubSpot, Hyperframes, Lovable, Miro, Netlify, Replit, v0, Vercel, Wix.
[ ] Not on that list: Figma (searched the help page, 2026-11-15).
[ ] Handoff to Claude Code needs a paid Claude plan (Claude Code isn't on Free).
[ ] Figma's connector: made by Figma, Anthropic verified, sign-in required; Figma lists the MCP server on all Figma plans.
[ ] Figma's limits for connector requests (tool calls): Starter plan, or a View or Collab seat, up to 20 a month; Full or Dev seat on Professional or Organization, up to 200 a day; Enterprise, up to 600 a day.
[ ] Claude side: web connectors are available for all users, Free included.
[ ] Frame into code: in Figma, right-click the frame, Copy link to selection; paste it into Claude and ask it to build the design.
[ ] Figma's own FAQ: the MCP server isn't a one-click way to finished code. Check what comes back.
[ ] Design system from Figma files: Anthropic's design-system page lists Figma files as a source in a chat (paid plans, beta).
[ ] Write to canvas (Figma beta): agents build frames, components, variables and auto layout in your Figma file.
[ ] Write to canvas needs: Professional, Education, Organization or Enterprise Figma plan; edit access; a Full seat to write outside your drafts; the remote Figma MCP server; a supported client (Figma lists Claude Code and Claude Desktop).
[ ] Write to canvas cost: free during the beta; Figma says it will become a usage-based paid feature.
[ ] Before writing to a real file: test on a duplicate or a draft file, and keep a backup (Figma's caution).
[ ] Shortcut: after the first prompt with a link, keep going in the same chat; the agent usually assumes the same file.
[ ] Also from Figma: Send UI to Figma captures a running app as flat layers (select clients only). Not a Claude Design export.
[ ] At work: follow your employer's rules before connecting company files.
