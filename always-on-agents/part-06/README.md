# Always-On AI Agents, Part 6: ChatGPT Dots Explained: What It Does, Who Gets It, and Is Pro Worth It?

Free files for the video. Facts checked 2026-11-27 on OpenAI's own pages; OpenAI changes these pages often, so open each source before you rely on a line.

- `dots-checklist.md`: the setup-and-safety checklist for ChatGPT dots: who can get one (Pro, 18 and over, outside the European Economic Area, the UK and Switzerland, and what OpenAI's pages each say about Plus), what Pro cost when checked ($100, $200 or $500 a month, billed monthly), what a dot is for next to ChatGPT Work, what it can reach, how to set when it asks first with Custom rules, and how to pause or delete it and what that doesn't undo, with OpenAI's words and a source for every line.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable, tickable copy of the checklist as one local web page. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video's description.
- `SOURCES.md`: every page the facts come from, with the date it was checked.
