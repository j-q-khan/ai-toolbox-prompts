# Always-On AI Agents, Part 2: Gemini Spark Is Now Task: How to Use Google's Free Always-On Agent

Free files for the video. Facts checked 2026-11-26 on Google's own help pages; Google changes these often, so open each source before you rely on a line.

- `task-in-gemini-checklist.md`: the setup-and-safety checklist for Task in Gemini (called Gemini Spark until Google renamed it): who can use it, how to turn it on, what it can reach, the permission answers, how to stop a task, how to delete it and what deleting leaves behind, with Google's words and a source for every line.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable, tickable copy of the checklist as one local web page. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Nothing was signed up for, signed in to or run for the video. Not affiliated with Google, xAI, Anthropic, Meta or OpenAI.
