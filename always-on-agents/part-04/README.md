# Always-On AI Agents, Part 4: Claude Duet Explained: Who Can Get It and What It Does for You Each Day

Free files for the video. Facts checked 2026-11-26 on Anthropic's own Claude Duet pages; Claude Duet is a research preview and these pages change often, so open each source before you rely on a line.

- `claude-duet-checklist.md`: the setup-and-safety checklist for Claude Duet: who can get it (plans, both pages' country lists, the invitation), prices when checked, joining the waitlist and signing in, what it can reach, what it's designed to ask before doing, and how to disconnect it and delete what it keeps, with Anthropic's words and a source for every line. No Anthropic page shows a pause switch or an approval-settings page, and the checklist says so rather than inventing one.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable, tickable copy of the checklist as one local web page. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Nothing was signed up for, signed in to or run for the video. Not affiliated with Google, xAI, Anthropic, Meta or OpenAI.
