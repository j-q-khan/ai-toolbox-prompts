# Always-On AI Agents, Part 1: Gemini Spark vs Grok Bot vs Claude Duet vs Meta Muse vs ChatGPT Dots: Which AI Agent Fits You?

Free files for the video. Facts checked 2026-11-26; plans, prices and countries change often, so open each source before you rely on a line.

- `which-agent-checklist.md`: who can get Task (Google's renamed Gemini Spark), Grok Bot, Claude Duet, Muse and ChatGPT dots, the price when checked, what each can reach and how each asks before acting, in each maker's own words, with the date and a source for every line.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a local "which agent fits me" checklist page from the dated table. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Nothing was signed up for, signed in to or run for the video. Not affiliated with Google, xAI, Anthropic, Meta or OpenAI.
