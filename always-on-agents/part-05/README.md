# Always-On AI Agents, Part 5: Meta Muse: The Free AI Agent in WhatsApp, Explained (Plus Spark, Glimmer and Charm)

Free files for the video. Facts checked 2026-11-27 on Meta's own Muse pages; Meta changes these pages often, so open each source before you rely on a line.

- `muse-checklist.md`: the setup-and-safety checklist for Muse: who can get it (the US, Canada and the UK for people 18 and over, and Japan, Singapore and Australia also listed), the price in Meta's words, signing up on a new account, what it can reach, what it's designed to ask before doing, the ads and AI-training choices, and how to dial it down and delete what it keeps, with Meta's words and a source for every line. No plan prices: Meta's plans page didn't open for our checker, and the checklist says so rather than guessing.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a printable, tickable copy of the checklist as one local web page. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: the checklist above, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Nothing was signed up for, signed in to or run for the video. Not affiliated with Google, xAI, Anthropic, Meta or OpenAI.
