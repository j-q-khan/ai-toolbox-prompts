### 1. cowork-skill-request.txt
```
# Claude Cowork: skill-request prompt and checklist
# From Claude Cowork, Part 3. Facts checked 2026-11-22 from Anthropic's help pages. Written from the docs, not run.
# How to save this file:
#   Windows: open Notepad, paste this text, choose File, Save as, set the box called Save as type to All files,
#   and name it cowork-skill-request.txt
#   Mac: open TextEdit, choose Format, Make Plain Text, paste this text, and save it as cowork-skill-request.txt
# Menu names are as Anthropic's help pages gave them on 2026-11-22. If a menu looks different, check support.claude.com.

SKILL REQUEST PROMPT
# Copy only the paragraph under these two lines into a new conversation in the Claude app,
# after swapping every [square bracket] for your own job and details. The checklist comes after it.
Create a skill for my [weekly team update]. The format: [three sections, wins, blockers and priorities, each with at most three bullets]. The tone: [direct and factual, written for my manager to skim]. Here's an example of one that worked well: [paste one you were happy with]. Ask me questions about how I do this job before you build the skill, and show me the skill's instructions before you package it.

CHECKLIST
[ ] 1. Skills: every plan, Free included. Plugins: paid plans only (Pro, Max, Ultra, Team, Enterprise). Cowork: paid plans only.
[ ] 2. Setting: Settings, then Capabilities, then "Create and edit files" on (older Settings layout: "Code execution and file creation"). On Team and Enterprise plans, the organization owner controls it.
[ ] 3. Find the page: in the Claude desktop app, click Plugins in the sidebar. On older screens it's called Customize (then the Plugins tab, then the Discover tab). If your message box shows Chat and Cowork, switch to Cowork first.
[ ] 4. Add one plugin from Anthropic's Knowledge Work marketplace (added by default): select it, look through its tabs, then click Add.
[ ] 5. Adding a plugin doesn't connect any app or sign you in. Check its Connectors tab.
[ ] 6. Some plugins in Anthropic's collection are made by other companies (Brand Voice is credited to Tribe AI). Add plugins only from sources you trust.
[ ] 7. Before real work, set the permission setting in the message box to Manual, so Claude asks before it acts.
[ ] 8. Use a skill: type / or click + in the message box, or describe the task.
[ ] 9. Check it worked: open the steps Claude took and look for the one that loads the skill.
[ ] 10. Make your own: start a new conversation, swap every [square bracket] in the prompt above for your own details, and send it.
[ ] 11. Save the skill file Claude makes, check it's among your skills on the Plugins page (skills filter), then test it in a fresh conversation, asking the way you normally would.
[ ] 12. Claude not using it? Check the skill is switched on, then name it in your request ("Use my weekly update skill").
```
