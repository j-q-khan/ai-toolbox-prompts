CHECKLIST
[ ] 1. Which problem? Cowork won't start, with an error: carry on at 2. No error, and no Cowork anywhere: go to 11.
[ ] 2. The error looks like "Missing HCS services: HNS, vmcompute, vfpext".
[ ] 3. Open PowerShell as administrator: Start menu, type PowerShell, right-click it, Run as administrator, choose Yes.
[ ] 4. Run command A1, press Enter, then run command A2 (Anthropic's check, two commands).
       Look for the feature showing as disabled, or the services missing.
[ ] 5. If so, run command B to re-enable the Virtual Machine Platform.
[ ] 6. Restart, NOT shut down and power on. (With Windows Fast Startup on, a shutdown can leave the
       virtualization services uninitialized.) Start menu, power button, Restart.
[ ] 7. Only if VMware or VirtualBox is also installed: in an elevated prompt (PowerShell as administrator),
       run command C and check that hypervisorlaunchtype is Auto. If it isn't, run command D, then Restart.
[ ] 8. Open the desktop app and start Cowork again. No error: done.
[ ] 9. Still failing? In Claude Desktop: Help, then Troubleshooting, then Show Logs. Review supported-features-info.json.
[ ] 10. Windows running inside a virtual machine without nested virtualization: not supported, Cowork can't run there.
[ ] 11. No error and no Cowork option? Anthropic documents two reasons:
        a. The message box shows no "Chat" or "Cowork" choice: you may have the new layout.
           Describe your task in any conversation.
        b. Claude was installed without admin access: Cowork on desktop isn't available. If you said No at install,
           Claude Setup showed "Administrator access is required to install Claude with full features" and exited.
           Save anything you need first (reinstalling can put data stored on your computer at risk),
           then run Claude Setup with administrator approval: get it from claude.com/download and choose Yes.
[ ] 12. Work computer and you can't choose Yes? Send Anthropic's page to whoever looks after your computers:
        administrators on Team or Enterprise plans can deploy Claude Desktop across the organization.

COMMANDS (Anthropic's page, 2026-11-22; each label line is ours, each command line is the page's)
# Command A1, Anthropic's check, part 1 (the page prints A1 and A2 together on one line):
Get-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform
# Command A2, Anthropic's check, part 2:
Get-Service vmcompute, hns
# Command B, re-enable the Virtual Machine Platform:
Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -All
# Command C, only if VMware or VirtualBox is installed (written in the page's text):
bcdedit
# Command D, only if hypervisorlaunchtype isn't Auto (written in the page's text):
bcdedit /set hypervisorlaunchtype auto
