# Claude build prompt: Real Estate Lead Generation with AI

**What you need:** Claude Code on a paid Claude plan (Pro or higher, at the time of checking), a test folder, and made-up test data. Never use real client details. Claude should ask you before it changes anything.

Part 9 of AI for Real Estate Agents. Copy everything below the line into Claude.
Use made-up test data only, never real client details.

---

Goal: in a new test folder, build three prospecting workflows with made-up data: score a Twenty-style CRM export with a local Ollama model, draft batched follow-ups, and prepare an n8n workflow that drafts website inquiry replies and waits for my approval. Inputs: create a dummy file prospects.csv with 20 made-up lines and the columns id, stage, source, last_contact_date, property_interest, notes, consent, do_not_contact; no real names, emails or phones. Steps: 1) Check that Python 3.10 or later and Ollama are installed, that a local model is pulled, and that Ollama's cloud features are off (OLLAMA_NO_CLOUD=1 or disable_ollama_cloud); list anything missing and how to fix it, and don't install or change settings yourself. 2) Write score.py that sends each line to Ollama's local chat API with a JSON schema in the format field (id, score 1 to 5, reason quoting the notes) and the schema repeated in the prompt, never using protected characteristics, then saves scores.csv with id, score, reason, ready to import back into Twenty by id into a Score number field I add first. 3) Write followups.md: one email under 80 words per id scoring 4 or 5, skipping do_not_contact and consent not yes. 4) Write inquiry-workflow.json for n8n to import by hand: a Webhook trigger, an Ollama Chat Model step drafting a reply only from given facts, a Gmail step using Send and Wait for Approval that emails the draft to me, and, only after I approve, a final Gmail send to a test address I give you. Don't import it or add credentials. 5) Write consent-check.md listing every step that sends a message, and where the consent and Do Not Call filter sit. Safety: work only in the test folder, dummy data only, never real client data, read-only first, and stop and ask me before running anything that changes data, installs software or sends anything. Output: prospects.csv, score.py, scores.csv, followups.md, inquiry-workflow.json, consent-check.md, and a checklist of what I must verify by hand.
