---

Goal: in a new test folder, set up a small personal A.I. assistant stack from this series, with every tool local or behind an approval step, and a map of which tasks stay with me. Inputs: dummy files only, which you create: sample-listing.csv with the RESO field names BedroomsTotal, BathroomsTotalInteger, LivingArea, YearBuilt, InteriorFeatures; sample-hoa.pdf I'll add myself with made-up rules; prospects.csv with 10 made-up lines (id, stage, last_contact_date, property_interest, notes, consent). Steps: 1) Check that Python 3.10 or later, Ollama, Docling and Docker are installed, and that Ollama's cloud features are off (OLLAMA_NO_CLOUD=1 or disable_ollama_cloud); list anything missing and how to fix it, and don't install or change settings yourself. 2) Write two Modelfiles: listing-facts (writes from the given fields only, "not provided" for gaps) and fair-housing-check (flags any phrase about who should buy, rather than the home). 3) Write a script that runs docling on sample-hoa.pdf and sends the Markdown to a local model for a summary that quotes each source line. 4) Write score.py that scores prospects.csv through Ollama's local API with a JSON schema (id, score 1 to 5, reason quoting the notes) and saves scores.csv. 5) Write project-instructions.md that I can paste into a Claude Project: fair housing rules, brand voice placeholder, "not provided" for gaps, flag every price or legal claim. 6) Write stack-map.md: each weekly task, the tool that helps, and the tasks that stay with me because they need my license, negotiation or my duty to the client. Safety: work only in the test folder, dummy data only, never real client data, read-only first, and stop and ask me before running anything that changes data, installs software, creates a model or sends anything. Output: the Modelfiles, both scripts, scores.csv, project-instructions.md, stack-map.md, and a checklist of what I must verify by hand.
