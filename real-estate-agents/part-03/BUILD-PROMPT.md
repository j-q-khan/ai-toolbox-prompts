---

Use this in Claude Code, in an empty test folder, with made-up listing data only. Goal: build a small listing-prompt kit that turns an MLS export into ready-to-paste ChatGPT prompts and flags field problems before any copy is written. Inputs: one CSV in this folder named test-listings.csv, with made-up rows and these RESO column names: ListingKey, BedroomsTotal, BathroomsTotalInteger, BathroomsFull, BathroomsHalf, LivingArea, ListPrice, YearBuilt, InteriorFeatures, Appliances, PublicRemarks, PrivateRemarks. If the file doesn't exist, create ten made-up listings first and show them to me. Steps, in order: 1. Look at the CSV and list its columns. Don't change it. 2. Write a script that, for each listing, builds a field block with every column except PrivateRemarks, which it must never copy anywhere. 3. Flag problems in checks.csv, one line per listing, with columns ListingKey and problem: BathroomsTotalInteger not equal to BathroomsFull plus BathroomsHalf, any blank field, PublicRemarks longer than [your MLS character limit], and any PublicRemarks phrase that names a type of buyer or household, quoted for my review. 4. For each listing, write prompts/ListingKey.txt holding four prompts: listing remarks, showing fact sheet, carousel plus email plus reel, and a fair housing compliance check, each with that listing's field block filled in and the rule "use only these fields". 5. Write a short README.md that says how to run it again on a new export. Safety: work only in this folder, use only made-up data, never real client or seller details, and never send anything anywhere. Stop and ask me before running anything that changes data, and before writing outside this folder. Output: the script, checks.csv, the prompts folder and README.md, then a summary of what each check found.
