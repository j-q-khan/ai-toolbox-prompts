### 2. notion-agent-checklist.md
```
# How to use the Notion Agent: checklist (facts checked 2026-11-17)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## What you need
- [ ] A Notion account, in a web browser or the desktop app. Same steps on Windows and Mac.
- [ ] Your plan: Notion's help centre says "Notion AI is available on Business and Enterprise Plans." Free and Plus list a "Trial of Notion AI": a limited number of responses, no number published. Check notion.com/pricing.
- [ ] For work: follow your employer's rules first.
- [ ] Made-up notes only while you learn (the test page prompt makes some).

## Open the agent and ask
- [ ] Click the face in the bottom corner of Notion. A chat opens.
- [ ] Type a question about your own notes and send it.
- [ ] Check: an answer appears in the chat. If Notion can't find one in your notes, its guide says it falls back on general knowledge, so ask which page the answer came from.
- [ ] To draft a page: open the agent and describe what you want. Notion's guide says "Notion AI writes directly on the page".
- [ ] For more context, type @ in the chat and pick a page.
- [ ] The agent is also in the left sidebar.

## In a page
- [ ] Edit with AI: highlight the text, select Edit with AI, type the change, then accept, discard or try again.
- [ ] Ask AI: hover over a block, click the six dots in the left margin, select Ask AI.
- [ ] On a trial: each Try again counts as another response. Reword your request once.

## In a database
- [ ] Hover over the property you want to fill and click its name.
- [ ] Select AI Autofill (or Set up AI Autofill), then Basic.
- [ ] Choose what it does (for example Summary, Translate, Key info or Custom autofill) and when it runs, then save.
- [ ] Check: the property fills in from each page's own text. Basic Autofill does not browse the web or look across your other pages. Notion lists it as included on Business and Enterprise plans.
- [ ] A new database: open a new page, click Database at the bottom, then Build with AI.

## What it can reach, and privacy
- [ ] "Notion Agent has the same permissions you do." If you can't view or edit a page, your agent can't either.
- [ ] "By default, your customer data is not used to train models." On Free, Plus and Business: "AI provider retains your data for 30 days or fewer, then deletes it."

## Shortcut
- [ ] With the Notion desktop app installed: Shift + Ctrl + J (Windows) or Shift + Cmd + J (Mac).

## Switch off afterwards
- [ ] Delete the test page when you're done: select ••• at the very top right of the page, then Delete. It goes to Trash, at the bottom of the sidebar.
- [ ] Autofill: while you are only testing, choose manually for when it runs (one of the choices Notion lists at set-up), so it does not run on its own. Notion's Autofill page gives no steps for switching it off afterwards (checked 2026-11-17).

Sources: notion.com/help/notion-agent ; notion.com/help/guides/everything-you-can-do-with-notion-ai ; notion.com/help/guides/notion-ai-for-docs ; notion.com/help/writing-and-editing-basics ; notion.com/help/autofill ; notion.com/help/notion-ai-faqs ; notion.com/help/complimentary-ai-responses ; notion.com/help/notion-ai-security-practices ; notion.com/help/duplicate-delete-and-restore-content ; notion.com/pricing
```
