# OpenAI Codex: which place, which plan, which limits (checked 2026-11-24)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save. Prices change often: check https://learn.chatgpt.com/docs/pricing

## The four places Codex runs
- [ ] The ChatGPT desktop app (Windows or Mac; Linux is in preview): open the ChatGPT dropdown and select Codex, then New chat.
- [ ] Codex Cloud (also called Codex web): on the web or in the desktop app, start a chat and choose Work in, then Cloud. Needs a ChatGPT sign-in.
- [ ] The Codex IDE extension: Visual Studio Code and compatible editors.
- [ ] The Codex CLI: a command-line tool you run in a terminal.

## What each plan gets (OpenAI's pricing page and help centre, checked 2026-11-24)
- [ ] Free: was $0 a month. "GPT-6 Luna at Standard speed in the desktop app, subject to rollout".
- [ ] Go: was $8 a month. The same line.
- [ ] Codex Cloud "is not included with Free or Go" (help centre).
- [ ] Plus: was $20 a month. "Codex on the web, in the CLI, in the IDE extension, and on iOS".
- [ ] Pro: was from $100 a month. "Plans at $100, $200, or $500 USD per month".
- [ ] Business: was $20 per user per month, billed annually, 2 or more users; $25 per user per month billed monthly.
- [ ] A key for OpenAI's API instead of a plan: "Codex in the CLI, SDK, or IDE extension", "No cloud-based features", billed at API prices.

## Usage limits, in OpenAI's words
- [ ] "These estimates are not fixed message limits".
- [ ] "Local messages and cloud chats share your plan's usage allowance. Weekly limits may also apply."
- [ ] "Pro plans currently have no five-hour limit."
- [ ] At the limit mid-task: "the agent will be able to continue working on that turn, subject to fair use limits."
- [ ] Check your limits: https://chatgpt.com/codex/settings/usage (in the Codex CLI, type /status during a session).
