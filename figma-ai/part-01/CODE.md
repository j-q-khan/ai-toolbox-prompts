### 2. figma-ai-checklist.md
```
# Figma AI for beginners: checklist (facts checked 2026-11-19, from Figma's own pages)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## What you need
- [ ] A Figma account. Starter is "Free limited access to Figma products" with 150 AI credits a day, up to 500 a month (pricing page, checked 2026-11-19): https://www.figma.com/pricing/
- [ ] Figma in a web browser or the desktop app. The agent isn't on mobile.
- [ ] Before you put work files in: ask your admin how the Content training setting is set (see Privacy below).

## The Figma agent (changes the designs you have)
- [ ] Open a design file, select any layer, click Agents. Or press Cmd + Enter (Mac) or Ctrl + Enter (Windows).
- [ ] For a chat that stays open, click Agents in the left navigation bar. In the desktop app you can pop the panel out into its own window.
- [ ] Type what you want and press Send. A loading indicator shows on the canvas while it works.
- [ ] Don't like it? Click Undo in the chat to revert the most recent change.
- [ ] Can it edit? Full seat with edit access: chat and edit. View, Dev or Collab seat: chat only. Your own drafts: anyone can chat and edit.
- [ ] Plans listed: Starter, Professional, Education (not K-12), Organization, Enterprise. Some features need a paid plan.
- [ ] Figma's page lists coming soon: vector editing and Draw tools, icons, slots, prototyping and interactions. Not supported: exporting assets, diagrams and data visualizations (use Figma AI in FigJam).
- [ ] Ask it how-to questions about Figma; it answers from Figma's Help Center.

## Figma Make (builds a clickable app from an idea)
- [ ] Plans: Starter, Professional, Education (not K-12), Organization, Government, Enterprise.
- [ ] Copying a preview back into Figma Design as layers needs a paid plan (not Starter).
- [ ] You can publish an app as a website with its own address. You're responsible for the rights to any fonts, packages or images in it.
- [ ] Try book-club-signup-prompt.txt: paste it into Make's chat box, answer its two questions, check the page and its explanation.

## Credits
- [ ] Credits per month, when checked on 2026-11-19: Full seats Starter 500, Professional 3,000, Organization 3,500, Enterprise 4,250; Dev, Collab and View seats 500. Starter and View seats also have a daily limit of 150.
- [ ] Credits expire monthly and don't roll over, and seat credits can't be shared.
- [ ] Use credits: Figma Make, the agent, code layers, remove background, make or edit image, add interactions, Weave tools, and more.
- [ ] Free: AI search, Rename layers, Summarize and Cluster stickies and Update visual in FigJam.
- [ ] See your balance: Main menu, then AI balance. After a task, hover over the AI credits icon under the prompt to see what it used.
- [ ] What each task costs: Part 3 of this series, and https://help.figma.com/hc/en-us/articles/33459875669015-How-Figma-AI-credits-work

## Privacy
- [ ] The admin setting is called Content training. On by default for Starter and Professional teams; off by default on Organization and Enterprise plans. Figma doesn't use data from Education or Government accounts to train AI models.
- [ ] If it's turned off, Figma's AI terms say new content and edits added after that date won't be used to train AI models.
- [ ] The AI features setting (whether people can use Figma AI at all) is its own setting.
- [ ] Keep client files and personal details out unless your team's settings and your employer's rules allow it.

## For people who write code
- [ ] Figma's MCP server lets coding apps like Claude Code connect to Figma. Design to code: https://youtu.be/ah5iCrbRZcE . Code back into Figma: Part 6 of this series.

Sources: help.figma.com/hc/en-us/articles/37998629035799 ; /31304412302231 ; /33459875669015 ; /17725942479127 ; figma.com/pricing ; figma.com/legal/ai-terms
```
