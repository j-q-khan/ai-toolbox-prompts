# AI Music, Part 1: AI Music for Free: Suno vs Udio vs Gemini, What Each Free Plan Really Gives You

Free files for the video. Facts checked 2026-11-25; plans change, so open each source before you rely on a row.

- `lyric-and-prompt-template.txt`: the test song from the video (an original style prompt and six lines of lyrics written for it), plus a blank template for your own song. Genres, moods and instruments only; no artist names.
- `free-plan-checklist.md`: what Suno, Udio, Gemini (Lyria), ACE-Step and ElevenLabs free plans give you, in each maker's own words, with the date and a source for every row.
- `BUILD-PROMPT.md`: paste it into Claude Code in an empty folder to build a local comparison page of these free plans. It uses only the facts in the prompt, downloads nothing and runs no third-party code.
- `CODE.md`: both files above in one place, exactly as shown in the video.
- `SOURCES.md`: every page the facts come from, with the date it was checked.

Nothing in this folder was generated with any music tool, and no song was made for the video. This is not legal advice. Not affiliated with Suno, Udio, Google, ElevenLabs, YouTube or the ACE-Step project.
