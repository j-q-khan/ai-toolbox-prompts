# Claude build prompt: AI Music Part 3, a shot-list planner and YouTube posting checklist

Paste this into Claude Code in an empty folder on your computer. It builds one local web page that splits your song into clips of five to fifteen seconds, section by section, as a shot list you can work through in Suno Visuals or any image to video tool, plus a checklist for posting the video on YouTube. It downloads nothing, signs in nowhere, runs no third-party code and makes no audio or video. Written from Suno's, Google's and YouTube's help pages, checked 2026-11-26. Nothing here was run for the video.

Goal: build a single file called shot-list.html that turns my song's sections and their lengths into a numbered shot list of clips between 5 and 15 seconds, with a line for me to describe each shot, and shows a YouTube posting checklist under it.
Steps, in order:
1. Create shot-list.html in this folder, plain HTML, CSS and JavaScript in that one file, with no external scripts, fonts or images, and nothing fetched from the internet.
2. Add a song title box, a "Clip length" number box (default 10, allowed 5 to 15, and explain in one line that Suno Visuals clips are 5 to 15 seconds), and a table of sections where each row has a section name (for example Verse 1, Chorus 1) and a start time and an end time typed as minutes:seconds, with "Add section" and "Remove" buttons.
3. Add a "Make shot list" button. When I press it, check every row: the times must be valid, each end must be after its start, and the sections must not overlap. Show a plain one-sentence message for any problem instead of a shot list.
4. Split each section into clips: take the section's length divided by the clip length, rounded to the nearest whole number (at least 1), as the number of clips, and share the section's time out evenly between them in whole seconds that add up exactly to the section. If that makes any clip shorter than 5 or longer than 15 seconds, use one clip more or one fewer until every clip is between 5 and 15 seconds. If a whole section is shorter than 5 seconds, make it one clip and mark it "shorter than 5 s: merge it with the next section".
5. Show the shot list as a table: clip number, section, start, end, length in seconds, and an empty "Describe the shot" box for each clip. Under it, show the total number of clips and the song's total length.
6. Under the shot list, show this posting checklist with tick boxes: "AI use under Attributes in YouTube Studio set to Yes (the song is the main focus)"; "My own story and my own made-up character, not unrelated clips stitched together"; "Suno's watermark left in place"; "I read Suno's terms before trying to earn from it (no Suno page spells out commercial use for Visuals clips)"; "The song wasn't made on Suno's free plan if I plan to earn from it"; "Every name, face and lyric is my own". Add the date 2026-11-26 and one line saying these come from Suno's and YouTube's help pages and may change.
7. Add a "Copy shot list" button that copies the shot list as plain text, one clip per line, like "3 · Chorus 1 · 0:40 to 0:50 · 10 s · (my description)".
8. Fill the page with this example the first time it opens, so I can see it working: title "Bench at Nine", clip length 10, sections Verse 1 0:00 to 0:20, Chorus 1 0:20 to 0:40, Verse 2 0:40 to 1:00, Chorus 2 1:00 to 1:20, Outro 1:20 to 1:30.
9. Save what I type only in my browser's local storage, and add a "Clear" button. Don't send anything anywhere. Open nothing automatically. When you're done, tell me the file's full path and how to open it by double-clicking it.
Safety: don't download, install or run anything, and don't fetch any web page. Don't add any artist names, song titles or lyrics other than the ones I give you. Don't claim the checklist makes a video safe to monetise: it only reminds me what the help pages say.
Output: the path of shot-list.html and a two-line summary of what it does.
