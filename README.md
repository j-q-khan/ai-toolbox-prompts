# AI Toolbox prompts

Free prompts, build prompts, code and sources for the guide series on The AI Toolbox YouTube channel (@TheAIToolboxChannel). Each video's description links to its part's folder here.

| Folder | Series |
|---|---|
| [real-estate-agents/](real-estate-agents/) | AI for Real Estate Agents (10 parts) |
| [shopify-sellers/](shopify-sellers/) | AI for Shopify Sellers (11 parts) |
| [comfyui/](comfyui/) | ComfyUI (10 parts; more parts added as they publish) |
| [vikunja/](vikunja/) | Vikunja (6 parts) |

Each `part-NN/` folder has:
- **BUILD-PROMPT.md**: one prompt to paste into Claude Code. It builds that video's idea in a test folder with made-up data and asks before it changes anything.
- **CODE.md** (Shopify and some ComfyUI and Vikunja parts): the full code from the video, built from the official docs. Shopify code: try it only on a free development store, never on a store with real customers. Vikunja code: try it on a test instance with dummy tasks.
- **SOURCES.md** (Shopify, ComfyUI and Vikunja parts): every source the video's facts came from, with the date they were checked.

## Before you use anything here
- Use test data only. Never paste real client or customer details into an AI tool.
- Read what a prompt or script will do before you run it. Start with read-only access.
- Prices, plans and features change, so check the official pages. Nothing here is legal, tax or customs advice.
