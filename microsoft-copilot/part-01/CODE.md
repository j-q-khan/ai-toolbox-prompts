```
# Copilot in Word: prompt sheet (checked 2026-11-17)
# Use a test document and made-up notes only. Follow your employer's rules.

## 1. Draft (open a blank document, open Copilot, type this, paste the notes underneath, select Generate)
Write a one-page memo for my team about our move to the fourth floor, using these notes. Friendly and short.
(paste the made-up notes here)

## 2. Follow-up (type in the same box before you keep the draft)
Make it shorter.

## 3. Rewrite (select a paragraph, select Copilot, choose Auto Rewrite or type this)
Make this sound more formal.

## 4. Summarize (open Copilot from the document)
Summarize this document in five bullet points.

## 5. Check one result by hand
- [ ] Pick one bullet and find the line it came from in your notes
- [ ] Check every date, number and name in the draft against your notes
- [ ] Fix anything that doesn't match before you share it

## No Copilot button in Word?
- [ ] Work account, Copilot app: scroll to the bottom of the home page and look at the label under your name (a new home page is rolling out, so yours may look different)
- [ ] Copilot Chat (Basic): no Copilot in Word; paste your notes into Copilot Chat instead
- [ ] Microsoft 365 Family: only the subscription owner gets Copilot in the desktop apps
- [ ] Label says M365 Copilot (Basic) or (Premium) but no button: update Word, then ask the people who run your work accounts

Sources: support.microsoft.com "What Copilot license do I have"; "Draft and add content with Copilot in Word"; "Edit content and rewrite with Copilot in Word"
```
