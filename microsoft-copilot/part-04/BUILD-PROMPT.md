# Claude build prompt: Power Automate Tutorial for Beginners: Your First Flow from Outlook to Excel

Paste this into Microsoft Copilot (Copilot Chat) or into Claude, with made-up examples only. Follow your employer's rules on what you may automate and paste, and never describe real customers, staff or real mailboxes: use a test folder, a test table and emails you send yourself. It turns your own flow idea into a step-by-step checklist for Power Automate's cloud flows designer, so you can describe it to Copilot and then check every card it builds. Written from Microsoft Learn's Power Automate pages, checked 2026-11-17.

Goal: turn my automation idea into a checklist for one Power Automate cloud flow that I can build and test safely.
Steps, in order:
1. Restate my idea in one sentence in the shape "When X happens, do Y".
2. Name the trigger and each action, with the connector each one uses, exactly as Power Automate names them if you know them. If you're not sure of a name, write [CHECK: name in the designer].
3. For each connector, say whether Microsoft lists it as standard or premium, and if you're not sure, write [CHECK: standard or premium on the connector's Learn page].
4. List the settings to check on each card, and which values come from earlier steps.
5. Add a safety filter so the flow only runs on my test emails or test files (for example, a subject filter), and say where it goes.
6. Write a "When X happens, do Y" prompt I can paste into the box called Create your automation with Copilot.
7. Write the test steps: what to send or create, what a green check mark on each card means, and where to look for the result.
8. End with how to turn the flow off: My flows, the three dots beside the flow, Turn off.
Safety: test data only. The flow must not send anything to anyone but me, and it must only write to a test folder or a test table.
My idea: (for example: when an email with the subject Timesheet arrives with an attachment, save it to a Timesheets test folder and log the sender in a test Excel table)
