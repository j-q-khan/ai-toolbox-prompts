## 2. Check what I already have
- [ ] Open the Copilot app and look at the label under my name
- [ ] Label says Copilot Chat: Microsoft says it's "included at no additional cost with eligible Microsoft 365 plans"
- [ ] Copilot Chat (Basic) "can't use organizational data via Microsoft Graph": upload the file or work in the open one
- [ ] Copilot Chat (Basic) users "don't have access to Copilot in Word, Excel, PowerPoint, and OneNote"
- [ ] Label says Premium: the paid add-on, which reaches organisational data through Microsoft Graph

## 3. What each one can reach in my files
- [ ] Microsoft Copilot (paid add-on): "only surfaces organizational data to which individual users have at least view permissions"
- [ ] Claude, Microsoft 365 connector: SharePoint, OneDrive, Outlook and Teams; "can read or change only what your Microsoft 365 account can already read or change"
- [ ] Claude connector on Team or Enterprise: a Claude Owner adds it, and a Microsoft Entra Global Administrator grants tenant consent
- [ ] ChatGPT Work plugins: OpenAI lists SharePoint, Outlook Email and Teams; type @ and the plugin name to use one
- [ ] ChatGPT: OpenAI's fetched pages didn't state a permission rule for plugins; ask the people who run your accounts
- [ ] Any of them: a folder shared too widely is visible to an assistant that sees what you can see; ask for sharing to be tidied first

## 4. Where I'd use it
- [ ] Microsoft Copilot: built into Word, Excel and Outlook, with the right licence label
- [ ] Claude for M365 add-ins: Excel, PowerPoint and Word; Claude for Outlook "is currently in beta"; all four on Pro, Max, Team and Enterprise
- [ ] ChatGPT: one Microsoft add-in for Word, Excel and PowerPoint, "Available globally across all plans"
- [ ] ChatGPT for Word "does not automatically access files on your computer"
- [ ] Ask before installing any add-in: admins can deploy add-ins for everyone, or block the Office Store

## 5. Training, in each company's own words
### Work plans
- [ ] Microsoft (work account, Enterprise data protection): "the prompts, responses, and data accessed through Microsoft Graph aren't used to train foundation models"
- [ ] OpenAI (ChatGPT Business, pricing page): "No training on your business data by default."
- [ ] OpenAI (ChatGPT business page): "Your data is never used for training our models." (OpenAI's pages word this differently; the video quotes the pricing page)
- [ ] OpenAI (ChatGPT Enterprise): "Your business data, including conversations, files, and outputs from ChatGPT, is not used to train our models by default."
- [ ] Anthropic (Claude Team, pricing page): "No model training on your content by default."
- [ ] Anthropic (commercial products, e.g. Claude for Work, Privacy Center): "By default, we will not use your inputs or outputs from our commercial products"
### Home and personal plans
- [ ] Microsoft (Copilot in Microsoft 365 apps for home): "Prompts, responses, and your file contents when using Copilot in Microsoft 365 apps aren't used to train foundation models."
- [ ] Microsoft (the updated consumer Copilot app, 2026-08-18): training wording not found on 2026-11-17
- [ ] OpenAI (Free, Go, Plus, Pro): pricing page row "Content is used to train our models": "Opt-out available"; OpenAI's help page with the setting's name and default returned an error (403) on 2026-11-17
- [ ] Anthropic (individual plans): pricing page row "Model training": "Opt-out"; Privacy Center: "We will use your chats and coding sessions (including to improve our models) if:" you allow it in the Model Improvement setting; the page doesn't state the setting's default

## 6. Claude models inside Copilot
- [ ] Microsoft: "Microsoft offers third-party AI models in Microsoft Copilot, such as Anthropic and OpenAI models. As an admin, you can decide whether to use these models"
- [ ] Microsoft: Claude models are on by default for most commercial customers, "excluding EU/EFTA and UK"
- [ ] Microsoft: Product Terms, the DPA and Enterprise Data Protection apply, unless a model is labelled "Anthropic models with Data Retention" (off until an admin opts in)
