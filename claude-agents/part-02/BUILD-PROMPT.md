Goal: write a reviewer subagent for this repo that can look at the code but can never change it.
Steps, in order:
1. Look at this folder's file names and file types to see which languages and frameworks it uses. Only look; don't run any commands, tests or installs.
2. Create the file .claude/agents/reviewer.md (make the .claude and agents folders if they don't exist). If that file already exists, don't touch it: write .claude/agents/reviewer-2.md instead, with name: reviewer-2.
3. Start the file with YAML frontmatter between two lines of three dashes, with nothing above the first line, and exactly these four fields: name: reviewer ; description: one sentence saying it reviews this repo's code (name the languages you found) for bugs, security problems and readability without changing any files, and that it's for use after writing or changing code ; tools: Read, Glob, Grep ; model: sonnet
4. Don't add any other tool. No Edit, no Write and no Bash, because Anthropic's docs say a subagent with Bash can still change files through it. Don't add permissionMode, and never use bypassPermissions or dontAsk.
5. After the frontmatter, write the reviewer's instructions in plain Markdown: it reviews the files named in its task; for each problem it gives the file name and line number, says what is wrong and why it matters, and suggests a fix in words or a short snippet; it puts security problems first, then bugs, then readability, with checks that fit the languages you found; it never changes, creates or deletes a file; if something looks fine, it says so in one line and doesn't invent problems; it ends with the three changes it would make first.
Safety: write only that one new file. Don't open or change any other file's text beyond looking at names and types, don't run any commands, don't change any settings, and don't commit anything.
Output: the new file, then show me its frontmatter and one line I can type to try it: Use the reviewer agent to look over my recent changes and tell me what you'd improve.
