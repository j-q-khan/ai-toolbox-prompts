```
# Ask it this first: 8 first prompts for any chatbot (ChatGPT, Claude, Gemini or Microsoft Copilot).
# From AI for Beginners, Part 1. Facts checked 2026-11-21. Written from the makers' help pages, not run.
# How to save this file:
#   Windows: open Notepad, paste this text, choose File, Save as, set the box called Save as type to All files,
#   and name it ask-it-this-first.txt
#   Mac: open TextEdit, choose Format, Make Plain Text, paste this text, and save it as ask-it-this-first.txt
# How to use it: copy one prompt (not the lines starting with #), paste it into the chatbot's message box,
# and swap every [square bracket] for your own made-up or general details.
# Never paste passwords, bank details, health details or anyone's personal information.
# Check anything that matters (a fact, a number, a name, money, health, the law) against a trusted source.
# If you use it for work or school, follow your employer's or school's rules first.

1. Make this email friendlier, but keep it short and still say no: [paste your rough email here, with no real names]

2. Summarise this into 5 short points, then tell me the one thing I need to do: [paste a long document here, like a product manual or a public leaflet, never anything private]

3. Plan 7 cheap dinners for two people for next week, with one shopping list at the end. We don't eat [food].

4. Make me a packing list for a [number]-day trip to [place] in [month], grouped by bag.

5. Explain [a word or topic] in plain words, as if I've never heard of it, with one everyday example. Then ask me if I want it simpler.

6. I'm writing a short note to [who it's for] about [what it's about]. Write it in under 80 words, in a warm, plain tone.

7. Search the web first, then tell me [something recent, like opening hours or a price], and show me where you found it.

8. Where did that last answer come from? Tell me which parts I should check myself, and where I could check them.
```
