# Full code: AI for Beginners Step by Step: Your First Week of Using AI

The 7-day plan, written from the makers' official help pages (checked 2026-11-21). It was written from the docs, not run for this video.

### 1. first-week-with-ai.txt
```
# Your first week of using AI: one small job a day, with the prompt for each.
# From AI for Beginners, Part 3. Facts checked 2026-11-21. Written from the makers' help pages, not run.
# Works with ChatGPT, Claude, Gemini or Microsoft Copilot. Menus move, so look for the names in quotes.
# How to save this file:
#   Windows: open Notepad, paste this text, choose File, Save as, set the box called Save as type to All files,
#   and name it first-week-with-ai.txt
#   Mac: open TextEdit, choose Format, Make Plain Text, paste this text, and save it as first-week-with-ai.txt
# Swap every [bracket] for your own made-up details. Never paste passwords, bank details,
# health details or anyone's personal information. For work or school, follow their rules first.

DAY 1: PICK ONE, THEN KEEP YOUR CHATS OUT OF TRAINING
   Pick the one you can already get to: chatgpt.com, claude.ai, gemini.google.com or copilot.com.
   ChatGPT (website): account menu, Settings, Data controls, turn off "Improve the model for everyone", Done.
   ChatGPT (phone app): profile icon, Settings, Data controls, turn off "Improve the model for everyone".
   Claude: the menu under your name, Settings, Privacy, turn off "Help Improve our AI models".
   Gemini (website): History, then near the top click "On", then "Turn off".
     Google says chats are still kept with your account for around two months, and reviewers may still see some.
   Microsoft Copilot (new app): no switch. Microsoft says prompts, responses and your file contents
     "aren't used to train foundation models".

DAY 2: REWRITE AN EMAIL
   Where: the message box at the bottom of the screen.
   Prompt to paste:
   Rewrite this email so it's polite but still says no. Keep it under 100 words.
   [paste your draft here]
   Then ask for changes in the same chat: Make it warmer. Cut the last line.

DAY 3: SUMMARISE A LONG DOCUMENT (pick one that isn't private, like an appliance manual)
   ChatGPT: "+" in the message box, then "Add photos & files". Free plan: 3 file uploads a day.
   Claude: "+" in the lower left corner of the message box, then "Add files or photos".
   Gemini: "Add files", then "Upload", then "Files".
   Microsoft Copilot: copy the text from the document and paste it into the message box.
   Prompt to paste:
   Summarise this in five short points for someone who hasn't seen it.
   List anything I need to do, with any dates.
   Then open the document and check every date and number it gave you.

DAY 4: PLAN SOMETHING
   Prompt to paste:
   Plan a week of cheap dinners for two, with one shopping list.
   We already have: [list]. Please avoid: [list].
   Then push back in the same chat: Swap Tuesday for something without fish. Make the list shorter.

DAY 5: HAVE IT EXPLAIN SOMETHING, OUT LOUD
   ChatGPT: the "Voice" icon where you type (website: the prompt window; phone app: the message bar).
   Claude: the sound-wave symbol in the lower right of the chat window (on every plan).
   Microsoft Copilot: the microphone button (Microsoft's page doesn't say where it sits).
   Gemini: the phone app's spoken mode, at the bottom of the screen.
   Prompt to say or paste:
   Explain how interest on a savings account works, like I'm twelve.
   Then ask me one question to check I've got it.

DAY 6: CHECK ONE ANSWER
   Pick one fact or number from this week.
   Prompt to paste:
   Search the web, then answer, and show me where you found it.
   ChatGPT: "View all tools", then "Search". Claude: its web search answers come with citations (links).
   Gemini: the "Sources" button at the bottom of the response. Copilot: a "Sources" button below the response
     (Microsoft says the app may look different).
   Open one link yourself. Does the page really say that? No link? Check an official website.

DAY 7: WHICH TOOL FOR WHICH JOB
   For everyday writing, summing up, planning and explaining, any of the four will do. Stick with yours for a few weeks.
   Gemini sits inside Gmail on Google's paid plans; Copilot sits inside Word and Outlook with some Microsoft 365 plans.
   A question you don't want kept in your history? A temporary chat. Claude: the ghost icon at the top right of a new chat.

PRICES (US, each was this when checked on 2026-11-21; check the maker's page before you pay):
   ChatGPT Go $8 a month. Google AI Plus $4.99 a month. Microsoft 365 Personal $9.99 a month.
   Claude Pro $20 a month, billed monthly.
```
