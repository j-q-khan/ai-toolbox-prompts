# Claude build prompt: AI CAD with Claude, Part 6

Prepares a test folder for the FreeCAD MCP server (freecad-mcp 0.1.30) with the locks from the video: a Claude Code settings file that asks before every code run and blocks the tools you don't need, setup steps for your system, a code-review checklist, prompts and a safety checklist. Claude installs nothing and runs nothing; you run every command yourself. Written from the freecad-mcp docs (v0.1.30) and Claude Code's docs, checked 2026-11-07. Not run by us.

Use this in Claude Code (Pro or higher), in a new, empty test folder. Start in plan mode.

Goal: prepare this folder for the FreeCAD MCP server (freecad-mcp 0.1.30) with the locks from the video, and give me the commands to run myself. You install nothing and run nothing.
Inputs: my operating system (ask me: Windows, macOS or Linux), and whether I already have uv.
Steps, in order:
1. Tell me which files you'll create and wait for my yes. Only create files in this folder. Don't install, download or run anything, and make no web requests.
2. Write .claude/settings.json with exactly this permissions block: ask on mcp__freecad__execute_code and mcp__freecad__execute_code_async; deny on mcp__freecad__execute_code_headless and mcp__freecad__run_fem_analysis. Show it to me.
3. Write setup-steps.md for my system: the add-on zip link https://github.com/neka-nat/freecad-mcp/archive/refs/tags/v0.1.30.zip and which folder to copy (addon/FreeCADMCP, the one with InitGui.py directly inside); how to find FreeCAD's add-on folder with the one-line snippet in FreeCAD's Python console; restart FreeCAD, pick MCP Addon, click Start RPC Server, and leave Remote Connections and Auto-Start Server unticked; the uv install page if I don't have uv; then, from this folder, claude mcp add --transport stdio freecad -- uvx freecad-mcp@0.1.30; then claude mcp list, and the real test: ask which documents are open in FreeCAD.
4. Write code-review.md: a checklist I go through before I say yes to any execute_code call: only FreeCAD, Part, PartDesign and Sketcher imports; no os, subprocess, socket, urllib or requests; no file paths, open(), save, export or delete of files; no exec or eval of text from elsewhere; nothing I don't understand. If any line fails, I say no and ask why.
5. Write prompts.md with four prompts: list the open documents without changing anything; build a test part in a new document, showing the full code before each run, with the rules from code-review.md; report the bounding box, volume and whether the shape is valid before showing any picture; change one size and report the numbers again.
6. Write safety-checklist.md: add-on and server both at 0.1.30; maintainer and version checked on PyPI against the GitHub repo; Remote Connections and Auto-Start Server unticked; Start RPC Server only while working and Stop RPC Server after; the settings file in place before starting Claude; a backup of any real file before Claude touches FreeCAD; I save and export myself; only the test document open in FreeCAD while Claude is connected; test parts only, never a client's files; when finished for good, claude mcp remove freecad --scope local, delete the FreeCADMCP folder from FreeCAD's Mod folder, and delete freecad_mcp_settings.json one folder above it. Then give me a three-line summary.
Safety: this folder only, test parts only. You run nothing and install nothing; I run every command myself after reading it.
Output: .claude/settings.json, setup-steps.md, code-review.md, prompts.md, safety-checklist.md and a three-line summary.
