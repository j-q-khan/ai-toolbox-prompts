# Claude build prompt: AI CAD with Claude, Part 5

Turns your part's measurements into a FreeCAD 1.1 build card you can follow click by click in Part Design, plus a checker macro that builds the same part. Claude never runs FreeCAD or anything else; you run the macro yourself in a new, empty file. Written from the FreeCAD 1.1.4 source and the FreeCAD wiki, checked 2026-11-07. Not run by us.

Use this in Claude Code (Pro or higher), in a new, empty test folder. Start in plan mode.

Goal: turn my part's measurements into a FreeCAD 1.1 build card I can follow click by click in the Part Design workbench, plus a checker macro that builds the same part, without running FreeCAD or anything else.
Inputs: my part's description and sizes in mm. If I don't give one, use this test part: a headphone wall hook, a back plate 30 wide, 5 thick and 70 tall, an arm 45 out and 6 thick along the bottom, a lip 4 thick rising 10 above the arm at its end, two 4.5 mm screw holes centred across the width at 25 and 55 mm up, and the plate's two top corners rounded 5 mm.
Steps, in order:
1. Tell me which files you'll create and wait for my yes. Only create files in this folder. Don't install anything, download anything, run FreeCAD, Python or any other program, or make web requests.
2. Write build-card.md for FreeCAD 1.1.4: the side or face to sketch and the plane it goes on (XY, XZ or YZ) and why; for each sketch, the outline to draw from the origin, every dimension (with diameters, not radii, for holes) and the expected "Fully constrained" result; each Pad or Pocket with its Mode, Type and Length, using Mode Symmetric where it keeps holes centred; each Fillet with the edges to pick and the radius; then the mesh export: pick the Mesh workbench once, Edit, Preferences, Import-Export, Mesh Formats, Maximum mesh deviation 0.01 mm, then select the Body and File, Export, STL Mesh. Use the exact 1.1 labels: New Sketch, Polyline, Circle From Center, Dimension (D), Leave Sketch, Pad, Pocket, Fillet, Through all, Symmetric.
3. Write check_part.py, a FreeCAD macro that imports only FreeCAD, Part and Sketcher and builds the same part in a new document with a PartDesign Body, using body.Origin.OriginFeatures and each feature's Role to find the planes, AttachmentSupport and MapMode "FlatFace" for sketches, SideType "Symmetric" and Type "ThroughAll" where the build card says so, and edges picked by their geometry, never by a fixed EdgeN name. Every size goes at the top as a named variable with a comment. Add a comment saying it is checked by syntax only.
4. Write size-check.md: a table of every size I gave, where it appears in the build card and in the macro, and "match" or "check this"; plus anything you guessed.
Safety: this folder only, test parts only. You run nothing; I run the macro myself in a new, empty FreeCAD file, after reading it, because a macro is Python and can do anything a program can on my computer. So the macro imports only FreeCAD, Part and Sketcher, and has no os, file, subprocess or network calls; it only builds shapes in a new document. Nothing here is checked for strength: tell me to print and test any part that carries weight before trusting it.
Output: build-card.md, check_part.py, size-check.md and a three-line summary.
