# Claude build prompt: AI CAD with Claude, Part 4

Turns the OpenSCAD parts in a folder into Customizer-ready, parametric parts that use the BOSL2 library where it shortens the code, with a check table and two presets per part. Claude never runs OpenSCAD or downloads anything; you install BOSL2 yourself. Written from the BOSL2 wiki and README and the OpenSCAD manual (Customizer, Libraries), checked 2026-11-07. Not run by us.

Use this in Claude Code (Pro or higher), in your hook folder or an empty test folder. Start in plan mode.

Goal: turn any OpenSCAD part in this folder into a Customizer-ready, parametric part that uses BOSL2 where it makes the code shorter, plus a checker I can run my eye over, without running OpenSCAD.
Inputs: the .scad files in this folder. If there are none, write hook.scad: a headphone wall hook in millimetres, Z up, the wall at y = 0; a back plate 30 wide, 5 thick and 70 high with its two top corners rounded 5 mm; an arm 45 long and 6 thick along the bottom; a lip 4 thick and 10 above the arm at its end; two 4.5 mm holes for 4 mm countersunk wood screws at 25 mm and 55 mm up, each with a 90 degree countersink 8.5 mm wide at the front face.
Steps, in order:
1. Tell me which files you'll change or create and wait for my yes. Never run openscad or any other program, install nothing, download nothing and make no web requests. Ask me to confirm BOSL2 is installed in OpenSCAD's library folder (File, Show Library Folder; a folder named exactly BOSL2); I install it myself.
2. Add these rules to CLAUDE.md (create it if it's missing, keep any rules already there): BOSL2 is loaded only with include <BOSL2/std.scad>, never use, and no other include, use, import or surface line; every BOSL2 module and argument is checked against the BOSL2 wiki (github.com/BelfrySCAD/BOSL2/wiki), never BOSL version 1 code; every size the user may change sits at the top, above the first {, with a // description on the line above starting at the left edge and a // [min:step:max] range after the value, grouped with /* [Group name] */ comments; worked-out values and $fn go under /* [Hidden] */; an assert() with a plain message for any slider combination that would break the part.
3. Rewrite each part to those rules without changing its size or shape. Use cuboid() with rounding= and edges= only where it replaces hull() or minkowski() rounding of a box, and always give it anchor=FRONT+LEFT+BOT when it replaces a cube() that starts at the origin. Keep holes as plain cylinders with d=. Before writing, show me the old and new parameter blocks side by side.
4. For each part, write a table in check.md: every parameter, its default, its range, and what breaks at the smallest and the biggest value; every BOSL2 call with the wiki page it comes from; and every assert() you added with its message.
5. Write a .json presets file next to each part with two presets that set every parameter (the parameterSets format with "fileFormatVersion": "1", values as strings), each checked against the ranges and the asserts.
6. Finish with the steps for me to do by hand: open the file in OpenSCAD, Window, Customizer (2021.01: untick Window, Hide Customizer), tick Automatic Preview, try each preset, press F6, export the STL, and print and test the size I'll use before trusting it with any weight.
Safety: this folder only, test parts only. No programs run, no installs, no downloads, no web requests. Ask me before changing any file, and never overwrite a file without showing me the change first.
Output: the rewritten .scad files, CLAUDE.md, check.md, the .json presets and a three-line summary.
