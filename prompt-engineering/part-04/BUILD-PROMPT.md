Goal: rebuild one prompt of mine in two steps: add examples, then put each part inside its own tag.
Steps, in order:
1. Go through my prompt and tell me, in one line each, what it asks for, whether it already holds any examples of the result I want, and whether it mixes more than one kind of text (the request, examples, facts or a document).
2. If it holds fewer than three examples, ask me to paste up to five results I've been happy with. If I only have one, offer to draft two more that differ from it, and wait for me to approve or change them. Don't invent examples without asking.
3. Check the examples: do they match the task, and do they differ from each other in length, wording and case? Tell me if two are too alike, and say which pattern a reply might copy from them.
4. Rewrite my prompt with each part between a pair of tags. A tag is a word inside angle brackets; the closing tag is the same word with a slash in front. Put the request between instructions tags, each example between its own example tags with all of them inside one examples tag, and any facts or document I pasted between tags with a plain, descriptive name such as notes or document. Use the same names every time.
5. If my prompt is a one-line question with nothing else in it, say that it doesn't need tags, and leave them out.
6. Keep my meaning and my facts. Don't add facts I didn't give you.
Output: the rewritten prompt in one block I can copy, then a short list of what you changed and why.
