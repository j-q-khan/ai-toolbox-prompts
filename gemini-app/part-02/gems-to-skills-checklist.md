# Gems to skills: migration checklist (facts checked 2026-11-18)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## Does this apply to me now?
- [ ] Personal Google account, 18 or over: yes. Gems can't be used or edited since November 17, 2026, and are removed on December 17, 2026.
- [ ] Personal account, under 18: later; Google gives no date yet.
- [ ] Work account (Workspace business, enterprise, non-profit): March 2027.
- [ ] School account (Workspace education): June 2027.

## 1. Save your Gem's files first (before December 17, 2026)
- [ ] gemini.google.com: at the top, click Open Sidebar, then Gems (click More first if you don't see Gems).
- [ ] Next to the Gem, click Edit.
- [ ] Under Knowledge, click each file to open it, then at the top click Download.
- [ ] These won't carry over: GitHub files, audio, video, .doc, .xls, .ppt, and archives (.zip, .tar, .7z, .rar, .gz, .tgz).
- [ ] Over 100 MB of files in total? Google drops the largest first, so keep your own copies.
- [ ] Make a folder named like your skill: lowercase, hyphens between words (for example write-bakery-newsletter), and put the files in it.

## 2. Look for the skill Google made
- [ ] On the sidebar, click Customize (click More first if you don't see it), then Skills at the top.
- [ ] A skill with your Gem's name? Open it and check its instructions.
- [ ] Not there yet? Don't wait: do step 3.

## 3. Make the skill yourself
- [ ] Keep the Gem's Edit tab open and copy its name, description and instructions.
- [ ] In a new tab: Customize, then Skills, then near the top, Create, then Create manually.
- [ ] Paste the name, description and instructions (or use gem-to-skill-fields.txt).
- [ ] At the top of the skill, click Create.

## 4. Put your files into the skill (only if it needs them)
- [ ] On the Skills page, next to the skill, click More options, then Download. You get a .zip with a SKILL.md file.
- [ ] Open the .zip and move SKILL.md into the folder with your Gem's files.
- [ ] Next to the same skill, click More options, then Replace skill.
- [ ] In the upload area, click folder, pick your folder, then click Upload, and Upload again.
- [ ] The folder name must match the skill name. 100 MB in total at most.

## 5. Check it worked
- [ ] Start a new chat, enter / (or @ with the updated shortcut) and pick your skill.
- [ ] Give it the kind of request your Gem used to handle. Does it follow your instructions?
- [ ] Not quite? Open the skill on the Skills page, change the Description or Instructions box, then click Save at the top.
- [ ] Description starts with what the skill does and has a "Use when" sentence: Gemini checks only the name and description to decide whether to use it.
- [ ] Only 100 skills can be active at once. To stop one: open it, click More at the top, then Deactivate.
- [ ] Remember: skills don't work with Canvas, Deep Research, Create video, Create music or Guided learning yet.
