### 2. task-approval-checklist.md
```
# Tasks in Gemini: approval checklist (facts checked 2026-11-18)

To keep a copy: paste this into Notepad and save it with the box called Save as type set to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, before you paste and save.

## Can I use Tasks?
- [ ] 18 or over.
- [ ] Signed in with a personal Google Account (not work or school).
- [ ] History is on (Gemini History page: myactivity.google.com/product/gemini).
- [ ] Country: free of charge in the United States, Canada, Australia, India, Japan and South Korea. Elsewhere: Google AI Pro or Ultra. Not available in the European Economic Area, the United Kingdom, Switzerland or Nigeria.
- [ ] No Task below the text box after all of that? Google says it's rolling out, so it may not have reached your account yet.

## Before I submit a task
- [ ] It says what to do, when to run it and what to give back.
- [ ] Inbox, calendar or Drive tasks: Google Workspace is connected to Gemini (Connected Apps). Google: Workspace "needs to be connected to Gemini Apps".
- [ ] It says "Don't send, delete or buy anything without asking me first."
- [ ] No sign-in details, payment details or sensitive info in the task thread. If a website needs them, take control and type them on the page.
- [ ] Nothing from work, unless my employer allows it.
- [ ] I'm comfortable with Gemini doing this (Google: "only give it tasks you're comfortable with").

## When Gemini asks me to approve
Google says Gemini is designed to ask for review and confirmation before it completes certain actions: sending communications, deleting data, sharing sensitive info, making purchases, completing financial transactions, and filling out and submitting web forms. It's also designed to ask your permission in the task thread before it uses a browser, unless you've set that to Always allow.
- [ ] I've checked exactly what it will send, delete, buy or fill in, and where.
- [ ] Buying: the item, the price and the shop are right. With Google Pay checkout (United States), nothing is purchased without my go-ahead.
- [ ] I picked the narrowest choice: Allow once, rather than Allow for this chat or Always allow.
- [ ] Not right? Don't allow. Gemini stops and doesn't try another way.
- [ ] Heads up: some Google Calendar actions, like updating events and sending invites, are designed to work automatically, and Gemini can make bulk changes to private tasks in the Google Tasks app without asking, so review those requests before submitting.

## Checking it worked
- [ ] Click the task in the sidebar, then at the top of the thread, click the progress chip: each step shows as completed, current or planned.
- [ ] Any file Gemini made is in the task thread, with Open beside it.
- [ ] Wrong direction? Type the change into the text box while it runs; Gemini updates its work without losing progress.
- [ ] Cancel it: in the text box, click Stop.
- [ ] Up to 15 tasks can run at once. Scheduled tasks don't run if task mode is off (Settings, Task settings) or my device is off.

Sources: support.google.com/gemini/answer/16596215 ; support.google.com/gemini/answer/18766567 ; blog.google (Tasks in Gemini, Nov 17, 2026) ; gemini.google/release-notes
```
