# Claude build prompt: Blender MCP with Claude, Part 3

Turns a model you describe in everyday words into a piece-by-piece build plan for Blender MCP: a pieces table, one ready-to-send prompt per piece with its check prompt, the CLAUDE.md rules file and the save-and-check checklist from the video. Claude writes text files only: it uses no Blender tool, installs nothing and runs nothing. Written from the Blender Lab MCP source (v1.0.3), the Blender 5.2 manual and Claude Code's docs, checked 2026-11-10. Not run by us.

Use this in Claude Code (Pro or higher), in your blender-test folder from Part 2. Start in plan mode. It writes plain text files only: it doesn't use the Blender tools, and it builds nothing in Blender.

Goal: turn a model I describe in everyday words into a piece-by-piece build plan for Blender MCP, with one ready-to-send prompt per piece, plus the rules file and the save-and-check checklist from the video. You install nothing, run nothing and don't call any Blender tool.
Inputs: what I want to model (ask me; if I have no idea, use the desk phone stand: base 80 x 70 x 10 mm, back 80 x 8 x 100 mm leaning back 20 degrees, lip 80 x 8 x 20 mm), roughly how big it is, and which side is the front.
Steps, in order:
1. Tell me which files you'll create and wait for my yes. Only create files in this folder. Don't install, download or run anything, make no web requests, and don't use any mcp__blender__ tool.
2. Ask me up to five short questions about the model (its pieces, the overall size, the front, anything that must touch or line up). Then write pieces.md: a table with one row per piece, giving its name (Model_Part style, with an underscore, like Stand_Back), what it is, its size in millimetres (width, depth, height), where it sits next to the pieces before it, and any tilt in degrees with which way the top goes. Order the rows so each piece sits on something already built.
3. Write prompts.md: one prompt per piece, in this pattern: "Add the [what] of our [model]: [shape] [W] mm wide, [D] mm thick and [H] mm tall, named [Name], [where it sits]. Sizes are in millimetres; Blender's unit is the metre, so 80 mm is 0.08. Show me the full Python in this chat first and wait for my yes. Use only Blender's bpy and Python's math module: no os, subprocess, file or network calls, and don't save, open or export anything. Then focus the 3D viewport on [Name]." After each piece's prompt, add a check prompt: "Take a screenshot of the 3D viewport and tell me what you see. Then give me the location, rotation and size of [Name] in millimetres and degrees, from the tools' numbers. Don't run any code."
4. Write CLAUDE.md with exactly these lines, so Claude Code loads them every time it starts in this folder: a heading "Blender MCP modeling rules (Blender 5.2, Blender Lab MCP 1.0.3)", then one bullet each: Build one piece at a time, and only the piece I asked for. / Sizes are in millimetres. Blender's unit is the metre, so 80 mm is 0.08. Check the scene's units first. / Before any code runs, show me the full Python in the chat and wait for my yes. / Use only Blender's bpy module and Python's math module. / No os, subprocess, socket, urllib or requests; no file paths; never save, open, export or delete files. / Name every new piece in the Model_Part style (Stand_Back) and say its name back to me. / After each change, focus the 3D viewport on the new piece. / When I ask for a check, take a screenshot of the 3D viewport and give me the location, rotation and size in millimetres and degrees, worked out from the tools' numbers, without running code. / If a piece sits wrong (sinks in, floats or faces the wrong way), say so and show the fix as Python first. / If I say I changed something by hand, look at the scene again before changing anything. / Never touch a piece I didn't name. Ask me when a size or a position is missing; don't guess. Then a last line: These rules are guidance Claude follows, not a lock: the ask rules in .claude/settings.json are the lock.
5. Write save-and-check.md: before each prompt, File, Save Incremental in Blender; send one piece's prompt; look over the Python before saying yes (shapes, sizes and names only: no files, web links or other programs); a side view (View, Viewpoint, Right); the check prompt; if it went wrong, File, Open Recent, the last good number, and say no to saving the changes, because Control Z may not take back what Claude did; after any change by hand (Sidebar with the N key, Item tab, type the number then mm, Enter), tell Claude and ask it to look again; at the end, Stop MCP Server in the add-on's settings and untick Allow Online Access if nothing else needs it.
6. Show me pieces.md and the first prompt, then give me a three-line summary.
Safety: this folder only, made-up models only. You write text files and nothing else; I send every prompt to Claude myself, in Blender MCP, after reading it.
Output: pieces.md, prompts.md, CLAUDE.md, save-and-check.md and a three-line summary.
