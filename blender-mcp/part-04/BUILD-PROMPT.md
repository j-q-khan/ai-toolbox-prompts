# Claude build prompt: Blender MCP with Claude, Part 4

Turns a model you've built in Blender with Blender MCP into a print-prep plan: the video's three prompts rewritten for your pieces, an export settings card for Blender 5.2's STL exporter, and a slicer size check. Claude writes text files only: it uses no Blender tool, installs nothing and runs nothing, and you export the file yourself. Written from the Blender 5.2 manual, Blender's STL exporter source (v5.2.3) and the Blender Lab MCP source (v1.0.3), checked 2026-11-10. Not run by us.

Use this in Claude Code (Pro or higher), in your blender-test folder from Part 2. Start in plan mode. It writes plain text files only: it doesn't use the Blender tools, and it builds nothing in Blender.

Goal: turn a model I've built in Blender with Blender MCP into a print-prep plan: the three prompts from the video, rewritten for my pieces, plus an export settings card and a slicer size check. You install nothing, run nothing and don't call any Blender tool.
Inputs: my model's piece names and sizes in millimetres (ask me; if I have none, use the desk phone stand: Stand_Base 80 x 70 x 10 mm, Stand_Back 80 x 8 x 100 mm leaning back 20 degrees, Stand_Lip 80 x 8 x 20 mm), which piece the others stand on, and whether any piece is tilted.
Steps, in order:
1. Tell me which files you'll create and wait for my yes. Only create files in this folder. Don't install, download or run anything, make no web requests, and don't use any mcp__blender__ tool.
2. Ask me up to five short questions about the model: its pieces, the piece the others stand on (the base), any tilted piece and which way it leans, any part that's very thin, and my slicer's name (only so the checklist can say "your slicer"; don't look anything up).
3. Write print-prompts.md with three prompts in the video's pattern. Prompt 1: "Using the blender tools, give me every [Model]_ piece's scale and its size in millimetres, and say whether [each piece standing on the base] sits below the top of [Base]. Work it out from the tools' numbers; don't run any code." Prompt 2: "Make our [model] one solid for printing. On [Base], add one Boolean modifier per other piece, each Union with the Exact solver, named Union_[Piece] and using that piece. Don't apply them. Then hide those pieces in the viewport. If a piece only touches [Base] along an edge instead of sinking into it, stop and show me that fix first. Show me the full Python and wait for my yes. bpy only; don't save, open or export anything." Prompt 3: "Take a screenshot of the 3D viewport and tell me what you see. Then list [Base]'s modifiers and whether each is switched on. Don't run any code."
4. Write export-card.md, for Blender 5.2, by hand: Scene Properties, Units: Unit System Metric, Unit Scale 1, Length Millimeters (never change Unit Scale after building, because it only changes the numbers shown); any scale that isn't 1: hover over the viewport, A, then Ctrl+A, Scale; File, Save Incremental before prompt 2; after prompt 3, click the model in the viewport; File, Export, STL (.stl); tick Selection Only; Scale 1000 (Blender stores 80 mm as 0.08, and an STL file has no unit); Scene Unit unticked; Apply Modifiers ticked; leave Format, Batch, Forward and Up as they are; save as [model].stl in this folder.
5. Write slicer-check.md: work out the model's expected outer size in millimetres from the sizes and tilts I gave you, show your sums, and say it's an estimate; then: open the STL in my slicer and compare its size; if it's about a thousand times too small, export again with Scale 1000 rather than resizing it in the slicer; very thin walls are worth a closer look in the next video's checks.
6. Show me print-prompts.md and the expected size, then give me a three-line summary.
Safety: this folder only, made-up models only. You write text files and nothing else; I send every prompt to Claude myself, in Blender MCP, after reading it, and I export the file myself.
Output: print-prompts.md, export-card.md, slicer-check.md and a three-line summary.
