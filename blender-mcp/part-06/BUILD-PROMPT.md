# Claude build prompt: Blender MCP with Claude, Part 6

Turns the video's clean-up of an AI-generated model (Hunyuan 3D or Tripo) into a plan for your own model: the six prompts rewritten for it and a checklist from download to export. Claude writes text files only: it uses no Blender tool, visits no generator's site, installs nothing and runs nothing. Written from the Blender 5.2 manual, the 3D Print Toolbox 1.5.0 source and the Blender Lab MCP source (v1.0.3), checked 2026-11-12. Not run by us.

Use this in Claude Code (Pro or higher), in your blender-test folder from Part 2. Start in plan mode. It writes plain text files only: it doesn't use the Blender tools, it doesn't visit any generator's site, and it builds nothing in Blender.

Goal: turn the clean-up from the video into a plan for my own AI-generated model: the six prompts rewritten for my model, plus a checklist I tick off from download to export. You install nothing, run nothing and don't call any Blender tool.
Inputs: what my model is, the size I want its longest side to be in millimetres, my slicer's minimum wall if I know it, and which generator I used (ask me; if I don't say, use a desk phone stand, 100 mm, and leave the generator out).
Steps, in order:
1. Tell me which files you'll create and wait for my yes. Only create files in this folder. Don't install, download or run anything, make no web requests, and don't use any mcp__blender__ tool.
2. Ask me up to four short questions: what the model is, the longest side in millimetres, my slicer's minimum wall (or "don't know"), and the piece name I want in the Model_Part style (default Gen_Stand).
3. Write cleanup-prompts.md with the video's six prompts, using my piece name and size: 1, report the scene with the look-only tools; 2, rename, clear any parent keeping the transform, scale evenly to my longest side and apply the scale; 3, merge by distance at 0.1 mm (0.0001) and add a Decimate modifier, Collapse, Ratio 0.2, not applied; 4, apply the Decimate modifier and recalculate normals outside; 5, the 3D Print Toolbox's Check All with every line of bpy.context.scene.print3d_toolbox.get_report() as name and value pairs; 6, only if Shells is more than 1, split into loose parts and list them largest first, deleting nothing. Every prompt that runs code ends: "Show me the full Python and wait for my yes. bpy only; don't save, open or export anything."
4. Write cleanup-checklist.md: download the GLB from the generator's own site yourself (check its terms; the licence of Hunyuan 3D's open models 2.0 and 2.1 doesn't cover the EU, the UK or South Korea); new file, Length = Millimeters, Save As; File, Import, glTF 2.0; then for each prompt, Save Incremental first and what to look for in the code; tune Ratio by hand in the Modifiers tab; Face Orientation overlay, no red outside; what each bad Check All line means (non-manifold or bad contiguous: Part 5's Make Manifold prompt; Shells above 1: prompt 6, then delete tiny pieces by hand; thin faces: make it bigger or generate a chunkier model); export by hand with File, Export, STL (.stl), Selection Only ticked, Scale 1000, Apply Modifiers ticked.
5. Show me cleanup-checklist.md, then give me a three-line summary.
Safety: this folder only. You write text files and nothing else; I fetch the model, send every prompt to Claude in Blender MCP myself after reading it, and import and export the files myself.
Output: cleanup-prompts.md, cleanup-checklist.md and a three-line summary.
