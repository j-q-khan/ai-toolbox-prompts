# Claude build prompt: Blender MCP with Claude, Part 5

Turns a model you've built in Blender with Blender MCP into a print-check plan for the 3D Print Toolbox extension (1.5.0): the video's four prompts rewritten for your model, a card explaining every line of the toolbox's result, and a before-you-check list. Claude writes text files only: it uses no Blender tool, installs nothing and runs nothing. Written from the 3D Print Toolbox 1.5.0 source, the Blender 5.2 manual and the Blender Lab MCP source (v1.0.3), checked 2026-11-11. Not run by us.

Use this in Claude Code (Pro or higher), in your blender-test folder from Part 2. Start in plan mode. It writes plain text files only: it doesn't use the Blender tools, and it builds nothing in Blender.

Goal: turn a model I've built in Blender with Blender MCP into a print-check plan for the 3D Print Toolbox extension (1.5.0): the four prompts from the video, rewritten for my model, plus a card that explains every line of the toolbox's result. You install nothing, run nothing and don't call any Blender tool.
Inputs: my model's main piece name, the names of any modifiers on it that join other pieces, in order (ask me; if I have none, use the desk phone stand: Stand_Base with Union_Back then Union_Lip), and the minimum wall my slicer suggests, if I know it.
Steps, in order:
1. Tell me which files you'll create and wait for my yes. Only create files in this folder. Don't install, download or run anything, make no web requests, and don't use any mcp__blender__ tool.
2. Ask me up to four short questions: the main piece's name, the joining modifiers in stack order, my slicer's minimum wall (or "don't know"), and whether the model has a flat bottom that sits on the bed.
3. Write check-prompts.md with four prompts in the video's pattern. Prompt 1: "Using the blender tools, make [Piece] the active and only selected piece, in Object Mode. Apply its Boolean modifiers in order, [first] first, then [next]. Use bpy.ops.object.modifier_apply. Show me the full Python and wait for my yes. bpy only; don't save, open or export anything. Then list [Piece]'s modifiers." Prompt 2: "Make [Piece] the active and only selected piece, in Object Mode, and run the 3D Print Toolbox's Check All, leaving its settings as they are. Its operator is bpy.ops.mesh.print3d_check_all(). Put every line of bpy.context.scene.print3d_toolbox.get_report() into result as name and value pairs. Show me the full Python and wait for my yes. bpy only; change nothing else; don't save, open or export anything. Then tell me what each line means for printing." Prompt 3: the test-cube prompt from the video, unchanged (bpy only, a cube made from its corner points with the top face left off). Prompt 4: "Only if [Piece] has non-manifold or bad contiguous edges, and I've saved a version: make [Piece] the active and only selected piece, in Object Mode, then run the 3D Print Toolbox's Make Manifold, then Check All. Their operators are bpy.ops.mesh.print3d_clean_non_manifold() and bpy.ops.mesh.print3d_check_all(). Put every line of bpy.context.scene.print3d_toolbox.get_report() into result as name and value pairs. Show me the full Python and wait for my yes. bpy only; change nothing else; don't save, open or export anything."
4. Write result-card.md: one line per result the toolbox reports (Non-manifold Edges, Bad Contiguous Edges, Intersect Faces, Shells, Zero Faces, Zero Edges, Non-flat Faces, Thin Faces, Sharp Edges, Overhang Faces), what it means in plain words, the value I want (0, or 1 for Shells), and what to do if it's wrong. Say the toolbox's own defaults (Minimum Thickness 1 mm, Overhang 45 degrees) are starting points, not printer rules, and use my slicer's minimum wall if I gave one. Say a flat underside counts as an overhang but sits on the bed. Say Make Manifold changes the mesh for real, so save a version first, and that it can't merge overlapping pieces or thicken walls.
5. Write before-you-check.md: File, Save Incremental; apply the joining modifiers top first (most of the checks skip modifiers); run Check All; if anything changed after a fix, export again with File, Export, STL (.stl), Selection Only ticked, Scale 1000, Apply Modifiers ticked.
6. Show me result-card.md, then give me a three-line summary.
Safety: this folder only, made-up models only. You write text files and nothing else; I send every prompt to Claude myself, in Blender MCP, after reading it, and I export the file myself.
Output: check-prompts.md, result-card.md, before-you-check.md and a three-line summary.
