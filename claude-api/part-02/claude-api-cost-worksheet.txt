STEP 5. WAYS TO PAY LESS (from Anthropic's docs, 2026-11-22)
  [ ] A smaller model: the pricing page says Haiku for simple tasks, Sonnet for most work, Opus for the most complex reasoning.
  [ ] max_tokens: set a cap big enough for your longest real answer. Claude can stop sooner.
  [ ] Prompt caching: a cache hit on Opus 5.5 or Sonnet 5.5 is 0.05 x the input price. The first 5-minute save costs 1.25 x.
      It pays off after one cache hit. Prompts under 512 tokens aren't cached (no error is returned).
  [ ] Batches API: 50 percent off input and output, for jobs that can wait. Most batches finish within 1 hour;
      a batch not done in 24 hours expires. Batches and caching can be combined.
  With a batch: one call = (input cost + output cost) / 2 = $______

STEP 6. BEFORE YOU BUY CREDITS
  [ ] New users receive free credits to test the API (Anthropic's words; no amount is published).
  [ ] Credits are bought on the Billing page (platform.claude.com/settings/billing), expire one year from purchase,
      and are non-refundable. Failed requests aren't charged.
  [ ] Max, Ultra and Team plans include monthly API credits, spent before credits you buy.
  [ ] Set a monthly spend limit (platform.claude.com/settings/spend-limits). It can't go above your tier's cap
      (when checked: Start $500, Build $1,000, Scale $200,000 a month).
  [ ] Check the Usage page (platform.claude.com/usage) and the Cost page (platform.claude.com/cost) after your first calls.
