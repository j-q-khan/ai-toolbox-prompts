# Part 3: Agentic AI Examples You Can Try Today: Claude Cowork, ChatGPT Work and Copilot

Part 3 of 4 in the Agentic AI series: one small job each in Claude Cowork, ChatGPT Work and Copilot in Excel, written from the makers' own help pages, then how to keep it safe with approvals and how to spot prompt injection (facts checked 2026-11-22).

## What's here
- agent-approvals-checklist.md: the checklist from the video (before you start, what to always approve yourself, what to watch while it works, prompt injection, and where each tool's approval controls are), plus the three practice prompts and made-up Test Bakery notes, ready to save and use.
- BUILD-PROMPT.md: a prompt for Claude Code that turns the checklist into an approval plan for one task you describe. It uses only the checklist, writes one new file beside it, and asks before it writes anything.
- CODE.md: the same checklist, as shown in the video.
- SOURCES.md: every page the video's facts come from, with the date checked.

## How to use it
1. Save agent-approvals-checklist.md into a new, empty folder. In Notepad, set the box called Save as type to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
2. Before your first real task in any agent, go through "Before you start" and check which approval mode you're in.
3. To practise, paste one of the three prompts into Claude Cowork, ChatGPT Work or Copilot in Excel (plan mode), with the made-up notes, never real data.
4. Optional: open Claude Code in that folder and paste the prompt from BUILD-PROMPT.md.

Every example in the video (Test Bakery, its notes, slides, suppliers, orders and chart) is made up, drawn and labelled "Example output". Every app screen is drawn from the makers' help pages. Nothing was signed up for, installed or run for the video. Plans and features change: they are as the makers' pages showed them on 2026-11-22.
