Goal: using my file agent-approvals-checklist.md, make an approval plan for one task I want to hand to an AI agent.
Steps, in order:
1. Look only at agent-approvals-checklist.md in this folder. Don't open any other file, and don't use the internet.
2. Ask me to describe the task in one or two sentences, and which assistant I plan to use. If I don't have a task, use the made-up Test Bakery practice task in the file.
3. Go through every item in the checklist's "Before you start" section, and for each one, write what it means for my task: which files or accounts the agent needs, which it must not touch, and where my backups are.
4. List every action in the task that has real consequences (money, messages sent as me, deleting or overwriting files, signing in, sharing anything), and next to each one write "I approve this myself".
5. Write the stopping point I should put at the end of my request, in one sentence.
6. List the places in my task where outside material comes in (emails, web pages, shared files), with one line on what to watch for, using the checklist's prompt injection section.
7. Show me the whole plan in the chat and wait for me to say yes. Then ask me before saving it as my-approval-plan.md in this folder.
Safety: change nothing else. Don't edit, rename, move or delete agent-approvals-checklist.md or any other file. If my-approval-plan.md already exists, stop and ask me before replacing it. Don't run any commands. Don't add product facts, prices or settings that aren't in the checklist.
Output: the name of the new file, and the stopping point sentence.
