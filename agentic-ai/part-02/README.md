# Part 2: Agentic Workflow Explained: Workflows vs Agents, With Real Examples

Part 2 of 4 in the Agentic AI series: the one difference between a workflow and an agent (who picks the steps), Anthropic's five workflow patterns told with everyday examples, and when an agent is worth its cost (facts checked 2026-11-21).

## What's here
- workflow-or-agent.md: the decision sheet from the video (three questions, the five patterns, what to check before choosing an agent) and a prompt-chaining template with made-up practice notes, ready to save and use.
- BUILD-PROMPT.md: a prompt for Claude Code that runs the made-up newsletter job twice, first as a fixed-steps workflow and then as an agent, so you can see the difference. It uses only the decision sheet, writes two new files beside it, and asks before it writes anything.
- CODE.md: the same decision sheet, as shown in the video.
- SOURCES.md: every page the video's facts come from, with the date checked.

## How to use it
1. Save workflow-or-agent.md into a new, empty folder. In Notepad, set the box called Save as type to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
2. Before you build anything, answer the three questions in order: one prompt, a workflow, or an agent.
3. To try a workflow by hand, paste the template's prompts into any chatbot one at a time, with the gate check between steps 1 and 2.
4. Optional: open Claude Code in that folder and paste the prompt from BUILD-PROMPT.md.

Every example in the video (Test Bakery, its emails, newsletter, fair stall and cake description) is made up, drawn and labelled "Example output". Nothing was run for the video.
