# Part 1: Agentic AI Explained: Agentic vs Generative AI vs AI Agents

Part 1 of 4 in the Agentic AI series: what "agentic" means, and how it differs from generative AI and from an AI agent, in each company's own words (facts checked 2026-11-21).

## What's here
- is-it-agentic-checklist.md: the five-question "Is it agentic?" checklist from the video, ready to save and use.
- BUILD-PROMPT.md: a prompt for Claude Code that turns the checklist into a page you can print. It uses only the checklist file, writes one new file beside it, and asks before it writes anything.
- CODE.md: the same checklist, as shown in the video.
- SOURCES.md: every page the video's facts come from, with the date checked.

## How to use it
1. Save is-it-agentic-checklist.md into a new, empty folder. In Notepad, set the box called Save as type to All files. On a Mac, open TextEdit, choose Format, then Make Plain Text, first.
2. Use the five questions on any tool that calls itself agentic.
3. Optional: open Claude Code in that folder and paste the prompt from BUILD-PROMPT.md.

Every example in the video (the team lunch, the cafes, the invite) is made up, drawn and labelled "Example output". Nothing was run for the video.
