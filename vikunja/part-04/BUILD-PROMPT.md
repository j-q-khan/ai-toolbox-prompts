# Claude build prompt: Vikunja vs Todoist vs Plane

A needs-based comparison matrix for Claude Code. It asks about your needs, scores the three tools from a dated fact sheet, and only goes online (to the three official pricing pages) after you say yes. Facts checked 2026-11-04. Not run by us.

Use this in Claude Code (Pro or higher), in an empty test folder. Start in plan mode.

Goal: build a small, re-runnable comparison tool that scores Todoist, Vikunja and Plane against my own needs and writes a dated comparison matrix.
Inputs: my answers to your questions, saved as needs.json, and a fact sheet, facts.json, that you write from the facts below. No accounts, logins or API keys.
Steps, in order:
1. Ask me up to eight questions, one at a time: team size, phone or desktop first, budget per year, whether I already run a home server or Docker, must-have views (list, board, table, calendar, Gantt), whether I need sprints, time tracking, CalDAV sync, which AI assistant I want to connect, and the licence of the edition I'd install. Save my answers to needs.json and show it to me.
2. Write facts.json from these facts, each with its source page and the date 2026-11-04. Todoist (todoist.com/pricing): hosted only; free plan with 5 personal projects and 3 filter views; Pro US $5 a month billed yearly or $7 monthly, with calendar and table layouts; Business US $8 per user a month billed yearly or $10 monthly; official MCP server Doist/todoist-mcp (MIT), hosted with OAuth sign-in. Vikunja (vikunja.io/pricing, vikunja.io/help): AGPL-3.0, free to self-host, one container plus a database (SQLite for a handful of users); Cloud from 4 euros a month; List, Table, Kanban and Gantt views on every project; CalDAV sync called an early alpha with bugs; phone app in alpha; time tracking only in Vikunja Pro, in private beta; built-in MCP server since 2.7.0 with token-scoped tools; ChatGPT can't connect yet. Plane (plane.so/pricing, developers.plane.so): the Community Edition is AGPL-3.0 and the Commercial Edition is closed source (developers.plane.so/self-hosting/editions-and-versions); Cloud free for up to 12 users; Pro US $6 per seat a month billed yearly or $8 monthly; Business $13 yearly or $15 monthly; cycles (sprints), modules, five layouts (list, board, calendar, table, and a Gantt-like timeline), intake and pages on Free; time tracking on Pro; self-hosting needs 2 CPU cores and 4 GB RAM (8 GB recommended), and the main self-hosted install is the Commercial Edition with 12 free seats per workspace, while the open-source Community Edition is a separate install; official MCP server makeplane/plane-mcp-server (MIT).
3. Ask me before going online. Only if I say yes, fetch the three official pricing pages, read only (no forms, no sign-ups), and list any price that differs from facts.json, with today's date. Don't change facts.json without my yes.
4. Give each need a weight from 1 to 5 based on my answers, show the weights, and let me change them.
5. Score each tool from 0 to 3 on each need, using only facts.json, with a one-line reason per score that quotes the fact used. Treat missing facts as unknown, not zero.
6. Write matrix.md: the weighted table, the total per tool, the winner, the runner-up, and the single fact that would change the result. Also write matrix.html, a single self-contained page with the same table and sliders for the weights, no external scripts.
Safety: no accounts, no sign-ups, no installs, no API keys. Fetch only the three pricing pages, and only after my yes. Stop and ask me before running anything that changes data.
Output: needs.json, facts.json, matrix.md, matrix.html and a three-line summary.
