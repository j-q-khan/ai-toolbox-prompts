Full Claude build prompt: paste this into Claude (a new chat). It's a research and planning prompt: it plans a small set of pictures you want to make in the Gemini app (say, an invitation, a poster and a card for one event), using only Google's own help pages, and writes each first prompt and one follow-up edit, ready to paste into Gemini. It makes no pictures, calls no image tool, needs no files, and never asks for photos of anyone. Written from Google's Gemini image help pages, checked 2026-11-21.

Goal: plan a small set of pictures I'll make myself in the Gemini app, and write the prompts I'll paste into Gemini.
What I'm making them for: [the event or purpose, for example a garden party invitation]
How many pictures: [2 to 5]
The look I want: [a style, for example watercolor, charcoal drawing or cartoon illustration]
Shape: [tall, wide or square]
Steps, in order:
1. Say in one sentence what you'll make, and that you'll follow only Google's official pages: support.google.com/gemini/answer/14286560 (making and editing images), gemini.google/overview/image-generation (prompt tips and models), support.google.com/gemini/answer/16722517 (SynthID checks) and policies.google.com/terms/generative-ai/use-policy (the rules), with a link for every rule you use.
2. Ask me up to three short questions if anything above is missing. Never ask for names, photos, faces or anything personal.
3. Plan the set as a table: picture number, what it's for, what's in it, what it's doing, the background or setting, and the shape as an aspect ratio Google uses in its own example (for example 2:3 for tall).
4. Write one prompt per picture, each starting with create, generate or draw, naming the style, and describing what's in the picture, what it's doing and the setting, as Google's help page tips say. Keep the style words the same across the set so the pictures match.
5. For each picture, write one follow-up edit I can type in the same chat if a detail comes out wrong, in the form "change [one thing] and keep everything else the same".
6. Check every prompt against Google's Generative AI Prohibited Use Policy, and flag any prompt that uses a real person, a real brand or someone else's artwork, with a safer made-up alternative.
7. Remind me, quoting Google: editing isn't available to users under 18; Gemini adds an invisible SynthID watermark and a visible watermark; limits apply and Google publishes no number of pictures; starting a new chat for a new topic saves usage.
Safety: never ask me for photos, names, faces or personal details; never suggest removing or hiding a watermark; never write a prompt about a real, named person; if a rule isn't on an official Google page, say "not stated" instead of guessing; date every fact "checked on" today's date.
Output: the plan table, then the prompts as a numbered list, each followed by its follow-up edit, then a five-line checklist for making them in Gemini on a computer (Open Sidebar, Images, paste the prompt, Submit, Download full size).
